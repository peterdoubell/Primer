# Processed pituitary MRI source case 1

This reference is integrated only into Primer's MRI-sella module. It provides the published T1 contrast-enhanced MRI, supplied registered T2, tumour–gland complex annotation and combined carotid annotation from Pandit et al., Figshare 27894084 v1 (DOI 10.6084/m9.figshare.27894084.v1), under the dataset's explicit CC BY 4.0 licence. See ATTRIBUTION.txt for the source authors and terms.

All original source samples and header forms are retained. Three source-index plane families reconstruct each supplied volume exactly; the displayed planes are not newly acquired anatomical reslices. The provided 499 × 404 × 342 grid is 0.5 mm. Reported T1 acquisition was 0.488 × 0.488 × 1.5 mm; case-specific T2 acquisition parameters were unspecified. No additional image resampling, fitted registration, source-mask smoothing, erosion, component removal or header correction was applied by Primer.

Display uses the supplied sforms. The original annotation qforms instead differ by 22.5 mm; that discrepancy is retained, disclosed and unresolved. The case is not registered to the separate SPL atlas or a current patient.

The two source-mask boundary models preserve the supplied mask cells and sform coordinates. The tumour–gland complex does not independently separate tumour and normal gland. The combined carotid annotation does not independently label walls, branches or laterality. Boundary endcaps denote source-mask extent and do not establish vessel occlusion or biological walls.

Immutable public source objects use content-addressed URLs. Full remote readbacks verified 90 objects (82 plane packs, two models, four original NIfTI files and two historical source notices). The authenticated app relays bounded MRI ranges and model responses, checks upstream status/range/length, and keeps metadata private. The browser independently checks source checksums. No write credentials are shipped to the browser.

The retained research packet at docs/pituitary-case-source-review-20261101 contains the original preflight, full source matrices, source metadata, lossless reconstruction evidence, delivery receipts and authenticated synthetic phone/desktop reader comparisons. Its original preflight README describes the earlier pre-integration state. This document describes the integrated runtime.

Do the two laboratories agree?

Both laboratories measure the same dimensionless constant. Start with the lesson’s measurements, then change either result or its uncertainty.

Laboratory results

The comparison uses Δ = A − B and u(Δ)² = u(A)² + u(B)² − 2ρu(A)u(B). A positive correlation reduces uncertainty in the difference because shared errors tend to move both readings together.

A large standardized difference calls for checking the measurement model, uncertainty estimates and possible bias. The difference alone cannot identify which laboratory, if either, has a bias.

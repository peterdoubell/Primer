What the instrument model includes

The input is a constant-rate Poisson stream of ionising interactions entering the counting chain. The input rate already includes the effects of detection efficiency and geometry; it is not a measurement of a source’s activity. Event times are simulated, with no measured radiation data supplied.

A recorded pulse disables counting for a fixed time τ. Interactions during that interval are lost and do not extend it. This is the non-extendable dead-time model, rather than a complete gas-tube or pulse-height simulation. The schematic shows the counting chain; it does not calculate gas avalanches, pulse amplitudes, energy discrimination or pileup. The settings stay constant during a gate.

Equations and finite-gate assumptions

For input rate λ, independent waiting times are exponential: Δt = −ln(U)/λ, with 0 < U < 1. A pulse at time t is recorded if the counter is ready; the next recovery boundary becomes t + τ. The gate includes 0 ≤ t < T and starts live.

The time of the nth recorded pulse is Sn = Gamma(n, rate λ) + (n−1)τ. Thus P(N ≥ n) = P(Gamma(n, λ) < T−(n−1)τ). Differences of these tails give the plotted probabilities, mean and variance. The calculation truncates each tail at a numerical probability threshold of 10−13 and renormalises the retained distribution.

The steady output rate is λ/(1+λτ). It approaches 1/τ at high input rates. That steady-rate relation differs slightly from a finite gate that starts live. The displayed predictions use the finite gate, including its start and end boundaries. Removing recovery time recovers Poisson counts, whose variance equals their mean.

Live time is T minus the portions of recovery intervals inside the gate. Recorded count divided by live time estimates the input rate under this model; one gate still has sampling uncertainty. The counter settings do not model switching recovery time during an acquisition: each changed setting starts a new gate with the same seeded input stream.

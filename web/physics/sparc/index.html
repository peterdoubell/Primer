How the comparison works

The source stores each component as a signed speed term V. The inward acceleration budget uses V|V|, so a negative gas term contributes outward. Add the gas term to the disk and bulge terms after scaling each stellar term by its mass per unit light. The square root gives a baryonic circular speed where the sum is nonnegative.

The acceleration difference is (Vobs² − Vbar²)/R. The units shown are 10−10 m/s². Positive values indicate a shortfall in the chosen baryonic model. Negative values indicate that it exceeds the observed circular acceleration. The difference uses the source distances and inclinations and does not assume a halo shape.

Published velocity errors include fitting uncertainty and rotation asymmetry. Inclination, distance, correlated errors and uncertainty in the baryonic model can change the comparison. SPARC flagged Q3 curves as unsuitable for detailed dynamical analysis.

Classification differences in the sources

The review’s Table 4 and MRI captions refer to 1.5 cm for internal indentation; its Figure 11 diagram uses 1 cm. These original labels are retained.

ASRM MAC2021 defines a septate uterus using septum length greater than 1 cm measured from the bicornual line and leading-edge angle below 90°. It defines bicornuate morphology using external fundal indentation greater than 1 cm. Apply the selected framework with appropriate imaging and clinical review.

Counting word pairs: a tiny language model

A bigram model predicts the next word from the one before it, using nothing but counts from a corpus. Edit the corpus, choose a word, and read off the probabilities.

Algorithm

  1. Split the corpus into sentences, lower-case it and split it into word tokens.
  2. Add a start marker before each sentence and an end marker after it.
  3. Count every pair of neighbouring tokens.
  4. P(next | previous) = count(previous, next) ÷ count(previous). With add-one smoothing, add 1 to the top and the vocabulary size to the bottom.
  5. To generate text, start at the start marker and keep choosing the most likely next word.

# Prenatal development sequence

35 selected AI-generated educational images, from developmental Day 5 to Day 83 (pregnancy age 2w5d to 13w6d). The renderer is attached to Biology / Reproduction and Growth. `sequence.json` defines stage order and labels; the WebP files load individually. The GIF contains the same stages with short optical crossfades.

Images were created with the built-in image generator, using one shared camera reference. They use an illustrative transparent window and variable magnification. They are not clinical photographs, exact biological measurements, or a prediction of any particular pregnancy. Calendar dates and personal identifiers are not included in the lesson assets.

Sources: [UNSW Embryology](https://embryology.med.unsw.edu.au/embryology/index.php/Embryonic_Development), [NHS week-by-week guide](https://www.nhs.uk/best-start-in-life/pregnancy/week-by-week-guide-to-pregnancy/), and [ACOG dating guidance](https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2017/05/methods-for-estimating-the-due-date).

The original generated PNGs and exact prompts are retained in the local output archive. `tools/build_prenatal_sequence.py` encodes selected images for the player and GIF.

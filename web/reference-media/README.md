# Photorealistic anatomical illustrations

`shoulder-bones-illustration.png` was generated with the built-in image-generation tool using the registered BodyParts3D shoulder viewer as a visual reference. It is an illustrative rendering, not a clinical image or a validated replacement for the source mesh geometry. The interactive viewer preserves the registered source anatomy and identifies the individual structures.

Reference geometry: BodyParts3D © Database Center for Life Science, CC BY 4.0. Source: https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html . License: https://creativecommons.org/licenses/by/4.0/ . Generated appearance and texture are modifications.

Final prompt: Create a clean photorealistic medical illustration from the three bones in the reference viewer; preserve right shoulder orientation and scapula, proximal humerus and clavicle relationships; remove all interface; do not add soft tissue; use natural ivory cortical texture, restrained studio lighting and an uncluttered background. Prioritise geometric faithfulness, with no labels, arrows, lesions or branding.

The earlier soft-tissue triptych drafts were not shipped because their small-structure detail was not reliable enough for this reference.

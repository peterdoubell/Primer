# Independent SOOP native stroke review — 11 October 2026

**Source integration and the standalone runtime candidate are approved.** This
approval covers the exact 21 payload files and ten source assets in the frozen
integration proposal. It grants no clinical, fine anatomical or reporting-coverage
approval. The complete decision, original source-pointer hashes and final runtime
pins are in [independent-review.json](independent-review.json).

The [primary OpenNeuro dataset](https://openneuro.org/datasets/ds004889/versions/1.1.2)
declares CC0. An independent fresh download of the complete pinned repository tree
contains 24,898 entries and is not truncated. Every actual licence, notice, README
and dataset-description candidate was inspected: the root README and dataset
description are the only such files. Both original Git blobs were fetched and
verified. No contrary derivative or component notice was found. All eleven chosen
originals match the pinned tree and their original annex content identifiers.

The [accompanying paper](https://doi.org/10.1038/s41597-024-03667-5) has a separate
CC BY-NC-ND grant. The source package contains no paper artwork or full text.
The public dataset’s CC0 terms were assessed independently of that article grant.
The earlier ISLES redistribution NO-GO remains intact.

Seven complete original arrays retain 160,204,800 source samples and 313,939,968
decoded storage bytes. An independent direct NIfTI-header decoder verifies every
transport byte, original integer storage type, scaling constant, dimension and
selected sform. TRACE and ADC retain their singleton fourth dimension. T1 and
FLAIR retain separate native grids and independent cursors; no mask overlay or
registration to diffusion is asserted. The viewer preserves both stored integers
and header-scaled readouts, without assigning a physical ADC unit or threshold.

All three models are independently verified literal boundaries of their separate
original masks. They retain every exposed face, outward triangle and component,
including single-voxel selections. The acute model has 9,688 triangles, chronic
16,644 and combined 26,332. The original combined mask equals the other two
labels’ union, but the implementation reads the unchanged original combined file.
Signed mesh volumes equal source grid volumes. They are not clinical core volumes
or continuously measured tissue boundaries.

The source diffusion slices are 5 mm thick with approximately 6 mm centre spacing.
The literal sampling cells therefore span unacquired interslice intervals, which
the viewer explicitly discloses. The finer T1/FLAIR sampling does not prove equally
fine acquired tissue resolution. Defacing, scanner reconstruction and source
method uncertainty remain. The paper’s inconsistent T2/ADC/TRACE annotation wording
is not silently resolved, and the source names “acute” and “chronic” do not establish
new biological age or clinical certainty.

Fresh independent browser contexts at widths 1440 and 390 verify the actually
served final JavaScript hash. All seven complete source buffers match the originals
at both widths. Eighty-four native pixel frames, containing 6,390,272 RGB pixels,
match an independent direct-original display oracle exactly. Four hundred and six
stored/scaled/RAS readouts also match. Twenty captures were visually inspected.
Thirty mesh/camera draws retain the complete geometry.

Eight corrupted-source checks cover manifest, TRACE, geometry and lazy T1 loading.
Each clears the GPU and image planes, removes ready geometry metadata, disables
controls and permits a valid retry. Blank, equal and reversed display windows are
rejected. The owner’s extreme-window overflow failure is preserved in its scoped
amendment; the corrected finite ±1e308 window independently displays gray 128.
The first browser run overlapped that repair and is preserved offline as superseded.
A fresh final run, rather than that run, supports this approval.

Eight source tests pass. Browser errors and overflow are zero. Browser contexts
are closed, and the source owner closed its server. Authenticated Primer reader
integration, deployed delivery and production UI remain separate checks.

No source here supplies native CTA/CTP, vascular lumen/wall/collateral models or
named segmentation for every reported structure. Clinical review, fine anatomy,
the complete module standard and the whole goal remain unproven. This reviewer
changed no common curriculum, registry, backend or Git state.

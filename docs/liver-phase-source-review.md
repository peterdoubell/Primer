# Liver phase rules and source-access review

The liver workstream now has a reviewed rule/source baseline. The [ACR current-release page](https://www.acr.org/Clinical-Resources/Clinical-Tools-and-Reference/Reporting-and-Data-Systems/LI-RADS) still lists CT/MRI diagnostic v2018 separately from the v2024 treatment-response releases. The official core PDF was acquired from the current linked CDN, fingerprinted and inspected for its diagnostic size/feature table and major-feature definitions. No ACR table image or PDF is redistributed in the reader.

The LI-RADS walkthrough previously combined washout and capsule in one generic late-phase instruction and offered a size-independent LR-5 shorthand. It now distinguishes agent-dependent washout assessment from capsule evaluation, keeps transitional/hepatobiliary hypointensity separate, and asks for category assignment through the size/feature table with LR-M/TIV review. The general liver-mass walkthrough now prompts eligibility/exclusion review and avoids declaring benignity solely from small size. Reporting fields and the current diagnostic version remain intact. The ACR source link is available with the reporting sources.

The newly identified [AMPLIFAI v2 preprint](https://arxiv.org/html/2608.14778v2) describes multiphase CT with target-lesion and feature annotations, making it relevant to phase-specific representation needs. Its paper licence does not clear the dataset. The author's dataset declaration and current [Hugging Face metadata](https://huggingface.co/datasets/UM-IHC-CA2i/AMPLIFAI) identify CC BY-NC-SA 4.0, with manual access approval. No access request, terms acceptance, external message, CT download or commercial-reader reuse was performed. Public metadata revision and source snapshots are preserved. Access is not permission to republish commercially.

Any constituent dataset must be checked separately for its original image rights and native acquisition/annotation lineage. An eligible original image source would not automatically license AMPLIFAI's added masks, registrations or category labels. Dataset explanatory summaries are not substituted for the ACR algorithm, and a target-lesion mask does not establish every lesion, liver segment, vessel, duct or MRI feature required by both investigations.

# Biliary source atlas

The biliary lesson, biliary duct reporting and gallbladder ultrasound reference link to 20 original BodyParts3D 4.3 objects in 14 source groups. Original hashes and CRCs matched the existing source review. Every face index and Float32 vertex was preserved. Repeated objects remain independently selectable in source coordinates.

The viewer credits DBCLS and applies CC BY-SA 2.1 Japan to the adapted atlas assets. It covers the gallbladder, common hepatic duct, cystic duct, right and left hepatic ducts and selected tributaries. Separate common bile duct geometry, luminal continuity, wall layers, clinical variants and independent anatomy review remain open. Source contact findings are recorded in the original review.

The version-stamped 4.3 `concept-objfiles-list` maps FMA14668 to FJ3079 in both `is_a` and `part_of` and has no FMA14667 entry. The latter is the common bile duct concept in the [IFAA terminology](https://ifaa.unifr.ch/Public/TNAEntryPage/auto/part/EN/TAH2739%20P3%20EN.htm). [Clarkson and Whipple’s comparative study](https://pubmed.ncbi.nlm.nih.gov/30815072/) flagged the BodyParts3D common hepatic duct segmentation. The current viewer preserves the source label and directs readers to this evidence. No part of FJ3079 is assigned a new duct identity.

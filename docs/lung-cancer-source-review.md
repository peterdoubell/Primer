# Native CT and source segmentation review

NSCLC-Radiogenomics R01-001 now has a complete original diagnostic thorax CT and its referenced DICOM SEG, plus the public clinical table and original AIM case annotation. The [TCIA collection](https://www.cancerimagingarchive.net/collection/nsclc-radiogenomics/) and per-series API metadata identify CC BY 3.0 for these images and annotations. Source-page snapshots, hashes, required dataset attribution and the usage-policy review are preserved separately from anatomical approval. NSCLC-Radiomics is a different collection with noncommercial terms; its licence is not borrowed or conflated with this source.

The exact selected series has 304 original CT DICOM files (160,142,106 uncompressed bytes). The one SEG file contains 304 binary frames (10,130,036 bytes). Every file passed the publisher's supplied MD5 manifest and ZIP CRC, with independent per-file and archive SHA-256 fingerprints. The archive SHA values are local byte identities, not claimed publisher whole-archive hashes. Both acquisitions are terminal; no source download remains running.

Native correspondence checks match the patient, frame of reference, CT series, all 304 referenced source instances and all 304 slice positions. The supplied grid is 512 × 512 × 304, with 0.693359375 × 0.693359375 mm in-plane spacing and 1 mm native slice spacing. All CT orientations and spacings agree; no gaps, duplicated planes or shear were accepted. Native plane-coordinate differences are zero. CT display applies the original slope 1/intercept −1024 values; the optional rescale-type and bolus-agent tags are absent, and a contrast phase is not independently verified. No source voxels or labels were resampled or changed.

**The SEG target is held.** It explicitly labels the segment Heart and uses the corresponding Heart tissue code. Its 2,719 positive voxels occupy a small peripheral upper-thoracic region, rather than a complete heart. The separate AIM case annotation names a peripheral solid right-upper-lung mass and references the same CT series; clinical metadata report adenocarcinoma and right-upper-lobe location. These facts are recorded as separate evidence, not used to silently rewrite the SEG. The historical T/N/M fields have no independently verified edition here and are not relabelled as TNM ninth edition.

The [IDC source support discussion](https://discourse.canceridc.dev/t/mislabeled-segmentations-for-nsclc-radiogenomics/518) records acknowledgement of this collection mislabelling by IDC and TCIA staff in November 2023. The currently acquired case still contains Heart metadata. The restricted helpdesk ticket was not accessed and no email, forum message or request was sent. Current case-specific target identity, original annotation provenance and the full lesion boundary still require reconciliation and independent anatomical review before model naming or reader binding. A known metadata error does not automatically validate the geometric boundary.

The review folder contains unmarked native orthogonal CT views at two display windows, the corresponding original SEG contour views, and an unmarked local detail crop. The contour coordinates use exact integer pixel centres; no half-pixel origin shift, fitting or registration is introduced. Axial/coronal/sagittal index choices, crop ranges, source hashes and figure hashes are retained. Marked and detail views were inspected directly. These views support source review, not an invasion, solid-component, station-map, nodal-positivity or complete-staging claim.

Four analytical checks passed with scientific dependencies available: exact source-manifest verification, changed/missing source rejection, count/byte agreement, and native plane permutation with offset/duplicate rejection. The application environment passed the three dependency-free checks and explicitly skipped the NumPy plane check. The preserved scope checks also remain separate from clinical accuracy. No runtime figure/model or fidelity binding was added, so the known floor remains 8,163 obligations and all 843 lung-cancer representation obligations remain missing.

The separate [Mediastinal-Lymph-Node-SEG source](https://www.cancerimagingarchive.net/collection/mediastinal-lymph-node-seg/) is a next acquisition lead: its collection page identifies CC BY 4.0 for CT/SEG and clinical data. Only source metadata were inspected in this turn; no case or mask was acquired or clinically verified. A future nodal case needs its own source, diagnosis, station boundaries and coordinates. It cannot be merged with R01-001 or treated as evidence of nodal metastases for this patient.

# Fractions and reporting requirements release

This release adds an exact rational arithmetic workbench to `math.2.fractions` and corrects its companion fraction disk's exact-value labels and closed surface geometry. The original ten assessment objects, prerequisites, and illustration are preserved. Current numerical, geometry, authenticated-reader, responsive-layout and speech evidence is recorded in `../fractions-fidelity-review-20261026/`.

The brain requirements inventory adds 30 side-specific parts derived from 28 current reporting rows. All prior 210 brain parts and every non-brain inventory byte are preserved. `../reporting-requirement-reconciliation-20261026/` records the complete current reporting reconciliation and source-context limitations. Adding a requirement does not assert that an image, schematic or model fully represents it.

`runtime-inverse.json` records exact before/after byte deltas against commit `ae974fcda00827d4617de9ae52da519327dcc743`. The strict helper restores these bytes only for historical evidence checks; it rejects unknown changes. Prior source evidence is unchanged and does not validate new content. No native atlas assets, clinical approval, whole-subject completion, or whole-goal completion are claimed.

The unfinished circuits/induction implementation and the staged inferior-parietal source unions are excluded from this release.

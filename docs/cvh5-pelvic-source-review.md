# Original pelvic source model and section evidence

The [Wu et al. source](https://doi.org/10.1371/journal.pone.0132226) supplies a cadaveric CVH5 pelvic reconstruction and serial-section context. The [publisher correction](https://doi.org/10.1371/journal.pone.0140736) reports switched supplementary filenames. Direct content inspection resolves the original `.s003.pdf` as the embedded model and `.s004.pdf` as 93 section pages. The TIFF captions must not be used to infer file contents.

The retained model stream is 10,392,492 bytes, SHA-256 `90a7bbae314e1276c62fd9a3b0144bb8a9bacafc1f34f1cf36c4f26ed8b0fc3e`. It contains 181 top-level U3D blocks, 96 modifier chains and 47 named model nodes mapped to 47 distinct mesh resources. Native node names, source-order transforms, visibility fields and complete block-byte hashes remain attached. All geometry resource declarations use extension block `0x100`; experimental position/triangle interpretations are now retained in the [candidate review](cvh5-candidate-geometry-review.md), with whole-decoder and normal-attribute verification still unfinished. No topology, geometric fidelity or patient-axis registration is inferred from names or byte conservation. The parser follows [ECMA-363](https://www.ecma-international.org/wp-content/uploads/ECMA-363_3rd_edition_june_2006.pdf) for block, string, chain and model-node structure, without executing PDF actions or scripts.

All 93 source sections are retained in page order. Each PDF image is a 466×530 RGB JPEG with an external ICC profile. Poppler and pypdf independently recover identical JPEG streams. Lossless PNGs preserve every decoded RGB sample and the original profile. Native JPEG hashes, pixel hashes, profile hashes, PDF object IDs and retained-file hashes remain explicit for every page. The six context sheets show all pages; display thumbnails are separate from preserved native samples. Original highest-resolution section masters, physical spacing, clinical orientation and model-to-section registration remain unverified.

The publication grant is CC BY 4.0, with attribution and correction retained in the original XML. This applies to the acquired published artifacts; it does not establish rights to additional unpublished donor data. The source caption says 46 structures while the main text and decoded node inventory say 47; the discrepancy remains unresolved. The correction also calls the anterior pubovisceral/puborectal division arbitrary, so that partition cannot automatically supply a real anatomical boundary. Cadaveric shapes do not establish in-vivo acquisition geometry, tumour extension, pathological nodes, dynamic physiology or individual anatomy.

These artifacts are offline reference candidates for missing anal/pelvic anatomy, with no clinical approval, structure coverage credit or runtime promotion. Geometry decoding, full source correspondence, layer/laterality/course assessment and independent anatomical review remain necessary. Positive anal-cancer MRI and nodal examples still require separate clinical sources. Full radiology counts and image-rights counts are unchanged.

The native header now has an explicit typed record: profile bits 10, declared unit scale 0.001 metres per source unit, UTF-8 encoding 106, and file length matching every accounted byte. This declares millimetre-sized source units; it does not verify acquired spacing, clinical orientation or registration. The raw version fields remain recorded without claiming acceptance by a geometry decoder. The exact extension declaration identifies `RHAdobeMeshResource`, GUID `96a804a6-3fb9-43c5-b2df-2a31b5569340`, declaration type `0x100`, Right Hemisphere Adobe Systems and version 1.0. All 47 geometry resources require that extension; a standard CLOD-only decoder cannot substitute for it. Adobe's historical specification URLs returned 404 during this review, and no undocumented geometry decoder or coordinate scaling was applied.

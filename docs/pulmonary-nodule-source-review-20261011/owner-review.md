# Pulmonary nodules: native source candidate and complete scope proposal

This is a source intake and standalone runtime candidate for `ra.ct-pulmonary-nodules` / `rad.4.pulmonary-nodule`, based on main `781ac4e863dda3bcca9002ced356d70aba256657`. It does **not** establish clinical/commercial module grade, fine anatomical coverage, or authenticated Primer integration. Current curriculum and shared radiology registries are unchanged.

The current effective reference has five reporting steps, three remote example images, and a generic lobe model; its 13-question curriculum is preserved in `current-scope-snapshot.json`. The draft inventory covers all reporting fields, the goal, and every question. It enumerates 79 conditional groups and 625 required parts, with 1,875 unverified image/schematic/model obligations. Every actual nodule, neighbour, anatomical variant and timepoint still needs explicit instantiation; this is a floor, not a complete fixed denominator. Nodule masks grant no normal-anatomy coverage.

The selected complete source study is LIDC-IDRI-0525: 429 original CT instances, 512 × 512 × 429 stored samples (112,459,776 values), original unsigned 12-bit values in unchanged 16-bit words, and each instance's exact position/orientation and rescale slope/intercept. The pixel spacing is 0.53710938 mm. The original DICOM SliceThickness is **nominal reconstructed** 0.75 mm, distinct from the approximately 0.7 mm reconstruction centre spacing. Actual acquired collimation is unverified; SingleCollimationWidth and TotalCollimationWidth are absent. No uniform affine replaces individual positions. Five candidate original headers were reviewed before selecting this finer-grid case with differing solid/non-solid/part-solid assessments. [DICOM thickness definition](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.34.12.html)

All four original XML sessions and all 33 marks remain: eight drawn nodule annotations, eight small-nodule loci and seventeen non-nodule loci, including the original excluded contour. All eight released SEG and eight SR objects for this study are retained. The eight SEG objects contain 19,136,512 samples and 5,884 occupied cells. Every exposed sampling-cell face is retained in eight separate models: 6,284 faces / 12,568 triangles. There is no smoothing, resampling, decimation, component removal or reader-consensus union.

Source differences remain explicit. Every SEG says ContentCreatorName “Reader1”, while the original XML has four distinct reading sessions. The viewer uses original XML session indices without rewriting that metadata or pretending session identities carry across cases. SEG decimal coordinates differ slightly from the CT; both are retained. Overlay links source pixels by the actual referenced CT SOP. Meshes use exact original SEG frame centres with midpoint inter-frame sampling-cell faces; this is a labelled display adaptation, not histology. Original SR volume integrates continuous contours, and its maximal axial contour diameter is not a Fleischner mean caliper diameter. All 72 source SR characterizations and all 16 contour metrics match independently recomputed original XML values within the published six-significant-digit metric rounding. Native occupied-cell volumes remain separate quantities.

Primary CT `getImage` and SEG `getImage` archives contain the actual CC BY 3.0 license and TCIA usage policy. All case-series metadata identifies the same license and the relevant original/analysis dataset DOI. The source collection and standardized annotation collection also identify CC BY 3.0. The license, full dataset citations, modification description, TCIA policy link and downstream attribution requirement are retained. Dataset terms allow commercial/educational reuse and adaptations subject to those conditions; this is an owner rights review awaiting independent review. No article artwork is included, and no attempt was made to identify or contact participants. [Original dataset](https://doi.org/10.7937/K9/TCIA.2015.LO9QL9SX), [standardized annotations](https://doi.org/10.7937/TCIA.2018.h7umfurq), [TCIA usage policy](https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/)

All 429 original CT DICOM files remain individual unchanged source units. Large archival ZIPs stay in ignored private intake. Seven lossless contiguous transport chunks reconstruct the complete CT buffer and avoid a single file over Git's 100 MiB limit. The source payload is 480 files / 370,135,064 bytes; the largest file is 21,765,826 bytes. `integration-proposal.json` pins every one of the 483 runtime candidate files, including the three authored viewer/manifest files.

The scientific checker re-reads every original CT pixel, position, orientation and HU scaling, compares every original SEG sample, reconstructs all XML contours with inclusion/exclusion semantics, and independently compares every exposed face in actual world coordinates. Actual standalone Chromium checks at 1440 and 390 px match 66 complete native RGB planes to an original-DICOM oracle, exercise all sixteen model selections, all sixty-six XML mark selections, camera/keyboard controls, numerical drafts, extreme windows and native zoom. A corrupt reviewed manifest and corrupt native chunk are rejected, followed by exact-source recovery. There are no console/runtime errors or document-width overflow. This verifies the standalone fixture, not authenticated app routes or hosted source delivery.

Preserved failed observations include missing initial decoder dependencies; an initial one-ROI-per-frame assumption disproved by the genuine excluded contour; a missing semantic case in the SR checker; mobile fieldset overflow; and zoom that left small nodules outside the visible viewport. The source values were not changed to make any check pass. The overflow and viewport-centering fixes were followed by current reader checks. The initial legalcode URL returned 403; the canonical English legalcode.en returned 200. `getImageWithMD5Hash` lacks the LICENSE present in actual `getImage` archives, and the standardized dataset is returned through the LIDC-IDRI collection query with its separate analysis DOI. These observations remain private/historical evidence, not rebaselined source expectations.

`complete-clinical-question-proposal.json` preserves every original question, includes a bounded proposed version and a question-specific visual requirement list, and records all thirteen proposed reference answers scoring 1.0 with the existing grader. Ten question indices change: 1, 2, 3, 4, 5, 6, 7, 9, 10 and 11. The numerical answers 5 mm, 7.6 mm under an explicitly declared sphere assumption, and five years are retained. The corrections remove unsupported histological certainty, persistence-excludes-infection claims, PET-negativity reassurance, fixed investigation timelines, guaranteed later curability and “most growth is measurement” assertions. The reporting proposal separates single/multiple and solid/subsolid pathways, qualifies acquisition/measurement limits and provides unfilled assessment prompts. [Fleischner 2017](https://doi.org/10.1148/radiol.2017161659), [measurement statement](https://doi.org/10.1148/radiol.2017162894), [BTS guideline](https://doi.org/10.1136/thoraxjnl-2015-207168)

# Biliary source-object interfaces and proximity

The original twenty-object biliary packet now has a complete source-pair contact audit and an independent proximity record for all 190 unordered object pairs. This compares unchanged source coordinates analytically; it does not assemble or approve a biological duct tree, select same-label alternatives, repair caps or fit objects together.

All 16,114 original triangles were testable. Across 186,182 conservative candidate pairs, the inspection preserves 3,914 contacts beyond ordinary adjacency. None occurs within one original object, consistent with the prior separate self-contact results. Same-FMA-label source representations account for 2,276 contacts; different source labels account for 1,638. Thirty object pairs have such contacts. These counts are source geometry findings, not independent biological junctions, validated branch identities or clinical observations.

Original source label-group membership remains explicit. Ordinary exact shared-position/edge adjacency is allowed by the numerical method and is not itself anatomical approval. The tolerance is 1e-9 mm, not native acquisition resolution.

[All-pair proximity evidence](bodyparts-biliary-source-review/all-source-pair-proximity-review.json) retains original closest vertex indices and positions, exact shared-coordinate counts and source fingerprints for all 190 pairs. All source vertices in this packet are face-referenced; the proximity tool fails rather than claiming a surface bound from unused source positions. Nearest vertices provide only an upper bound on minimum continuous surface distance. Positive nearest-vertex distance cannot demonstrate a surface gap.

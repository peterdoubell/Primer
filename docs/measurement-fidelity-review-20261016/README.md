# Measurement workbench

This work addresses the actual uncertainty, calibration and experimental-fit topics in `phys.4.experiment`. The new workbench replaces that lesson's legacy clipped, fixed-expectation graph when the root integration mounts it. The authored media ID, heading and illustration remain. The ten-question map is in `concept-coverage.json`; unresolved discovery/compatibility claims remain explicitly open. This does not complete the full mathematics/physics/radiology goal.

## API and integration

`web/measurement-lab.js` exposes `window.PrimerMeasurementLab` and CommonJS exports. It has no framework, server, network or data-storage dependency.

- `model(operation,a,b)` gives the value, analytic Jacobian and SI unit metadata for voltage sum/difference, speed `L/t`, or ideal small-angle pendulum estimate `4π²L/T²`.
- `propagate({operation,a,b,ua,ub,rho})` propagates supplied standard uncertainties and covariance. Linear models give an exact variance relation; speed/pendulum propagation is first order. It does not assign distributions or coverage probabilities.
- `interval({operation,a,b,da,db})` maps a full rectangular set of allowed inputs, returning the four corners, exact extrema and separate first-order bound estimate. It assigns no probability distribution to those bounds.
- `repeatBudget({n,readingStd,calibrationStd,resolution,resolutionMode,target,offset,correction})` separates independent repeat variance, an explicitly selected resolution model, persistent shared calibration, and a recognized synthetic offset/correction. Resolution modes are `included-in-scatter`, `shared-uniform`, and `independent-uniform`.
- `summarizeReadings(values)` returns mean, sample variance/SD and estimated standard error. One reading returns null variance/SD/SEM, not invented zero uncertainty. `repeatReadings` supplies the lesson's five-reading example.
- `weightedLineFit(rows,{mode,intercept,slope})` accepts `{x,y,sigma}` rows. `mode='fit'` estimates intercept and slope; `'reference'` tests fixed coefficients. The result includes all observations, fitted values/residuals, normalized residuals, leverage, parameter covariance, chi-square and degrees of freedom.
- `fitExample(state)` supplies twelve deterministic teaching observations with scatter, common offset, a deliberately shifted ninth point, optional acceleration/model mismatch, supplied sigma and optional heteroscedasticity.
- `render(item,hooks,frame?)` accepts the existing `phys.4.experiment` media item. For the integrated reader, pass `modelFrame(item,hooks)` as the third argument; it fills `frame.canvas`, updates its readout/status and returns `frame.root`. Without a frame it constructs an accessible standalone shell. A different supplied scenario returns null. Four independent station states persist when switching views. `root.measurement.getState()`, `getModels()` and `reset()` support verification without replacing ordinary control interactions.

Numeric APIs reject non-finite/untyped inputs and invalid covariance/domains. Input magnitudes are bounded by 10⁶; positive standard uncertainties/bound half-widths must be at least 10⁻¹². Nonlinear time inputs and the full bounded time interval must remain at least 10⁻⁶ s, with nonnegative length. Fit sigma is positive within [10⁻⁹,10⁶]; fitting requires distinct x values and 3–10000 rows. Subnormal second moments or non-finite parameter covariance are rejected with an instruction to rescale x. These are supported computational domains, not universal physical validity limits. UI controls use narrower teaching ranges. Invalid UI drafts clear the affected plots and show an error; no stale result is presented as the new state.

## Quantities and assumptions

For sensitivities `gA,gB`, standard propagation calculates `gA²uA² + gB²uB² + 2gAgBρuAuB`. A positive-semidefinite decomposition avoids a negative variance caused by cancellation and retains exact shared-offset cancellation at ρ=±1. The signed covariance contribution is visible in the variance budget. A zero output estimate has undefined relative standard uncertainty. Nonlinear models show the denominator's relative standard uncertainty as a diagnostic, not a guarantee of adequate linearization; moments alone cannot bound a denominator or specify its distribution. The definitions follow [NIST TN1297 Appendix A](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty).

The bounded models are monotone in each variable over their accepted domains, so corner extrema give their actual rectangular-set image range. The nominal value need not be the centre. For the 1%/2% speed example, the exact relative limits are approximately −2.9412% and +3.0612%; the 3% symmetric first-order estimate does not enclose the exact range. These are set calculations, not standard uncertainty or confidence limits.

The repeat budget uses `s²/n + ucal² + uresolution²`. An additional rectangular ±Δ/2 resolution model contributes Δ²/12 when shared, or Δ²/(12n) when explicitly independent between repeats. Default `included-in-scatter` adds no term, preventing double counting. Repeated identical digital readings do not establish independent phases. A supplied calibration uncertainty remains after a recognized offset correction; an uncorrected common offset is a signed error, not a variance. The separate five-reading example reports the arithmetic mean and sample spread without claiming its data establish IID errors. These distinctions follow [JCGM100:2008 sections4.3.7 and4.3.10](https://www.bipm.org/documents/20126/2071204/JCGM_100_2008_E.pdf/cb0ef43f-baa5-11cf-3f85-4dcd86f77bd6).

The line fit treats x as exact and supplied y standard uncertainties as known and independent. Weighted least squares uses actual observations, not a preselected expectation line. Its parameter covariance is `(XᵀWX)⁻¹`, without residual-scatter rescaling. Residuals become correlated after fitting. Degrees of freedom are n−2 for the estimated line and n for the fixed reference. A chi-square distribution interpretation additionally requires independent Gaussian observation errors and the correct mean model; the deterministic teaching residuals do not establish these conditions. Low/high reduced chi-square does not uniquely diagnose a cause. A free intercept can absorb common bias while residuals remain small. No p-value is computed. See [PDG Statistics2025 section40.2.3](https://pdg.lbl.gov/2025/reviews/rpp2025-rev-statistics.pdf).

The fit preserves small x/y offsets relative to the first observation before forming central moments. Adding a weighted mean offset to a large origin too early lost translation invariance; independent review found this and the implementation was repaired. The exact regression with x near 999999 spaced by 2⁻³³ yields χ²=1/9, fitted values 8/9, 20/9, 32/9 and unchanged leverages after translating the origin. Rounded intercept/centroid presentation does not replace the centred evaluation used for predictions and residuals.

## Representation and checks

Every displayed observation and ±sigma bar remains within its dynamically labelled plot domain, including simultaneous maximum offset/scatter/outlier/acceleration. Normalized residuals use their own complete domain. The uncertainty curves show analytic model standard uncertainties, not sample paths or guarantees. SVG axes use explicit SI units or dimensionless labels; small/large tick values use scientific notation. Accessible tables retain all data. Native labelled controls, status/error messages, reset, independent instance IDs and internal enlargement support keyboard and narrow screens. Speech summaries include the active station's assumptions and values.

`node tools/check_measurement_core.cjs` independently checks analytic/finite-difference Jacobians, a four-point covariance construction, dense interval endpoints, explicit repeated-observation covariance sums, a modified Gram–Schmidt QR line solution/covariance, common-shift and sigma-rescaling invariants, translated tiny-spacing fixtures, sample statistics and invalid domains. The proof records 1,620 propagation cases, 324 interval cases, 405 repeat cases and 486 fit fixtures; counts do not imply full module coverage.

`tools/check_measurement_browser.cjs` mounts the current renderer with production styles, uses ordinary controls and independently reconstructs actual SVG point/bar/line coordinates. It covers 390 px and 1440 px views, all presets, field extremes, valid/error recovery, enlargement, reset, multiple instances, supplied-frame contract, text bounds and every native label. Screenshots and the exact source-bound proof are under `browser/`. This standalone verification does not establish authenticated lesson integration or production delivery; those are root-owned checks.

Only `/nodes/33/quiz/7` has been changed: the speed question now explicitly asks for independent standard uncertainties and first-order propagation, yielding 2.2% to one decimal. Exact before/after hashes and fields are in `curriculum-correction.json`. `unresolved-assessment-proposals.json` records further quiz4/5 issues and primary-source proposals; those changes have **not** been applied.

## Actual authenticated reader

`tools/check_measurement_reader.py` creates an isolated temporary SQLite database, content directory and backup directory, generates synthetic credentials and starts the real API entrypoint on loopback. The browser child receives the fixture on stdin; all proof destinations are fixed repository paths. The launcher terminates the server and removes its temporary directory on success or failure. It never uses production learner storage or Turso.

The final actual-reader proof in `reader/proof.json` covers **54 states** at 390 and 1440 px, all four stations and their extreme presets, invalid-domain recovery, internal enlargement/keyboard scrolling and eight real model-frame speech callbacks (captured without sound). The original media identity, heading, instructions and illustration are retained. The obsolete clipped `physics-concept-svg` is absent. The public node API excludes quiz content, and protected routes reject anonymous requests. Every fitted observation and uncertainty bar remains visible. The served startup bundle is byte-identical to the current script list (2,902,718 bytes). No page errors, CSP violations, horizontal page overflow or external requests were observed. This proves the isolated current reader, not production deployment.

Run the launcher with the scientific Python runtime and bundled Playwright in `NODE_PATH`. The numeric checker prints its result to stdout; set `MEASUREMENT_WRITE_PROOF=1` to refresh its fixed proof file. Browser and reader tools always use fixed output locations, never caller-selected filesystem paths.

# Reporting compartments — 28 October 2026

All 225 investigations now carry ordered `compartments` (stable presentation ID,
label, section IDs). Each existing section carries `compartment`; its authored
`group` remains the subgroup. The shared sheet uses bordered, collapsible regions,
open by default, with jump navigation, selected counts and compartment-scoped
Normal remaining. Copy and REST/MCP composition use the same compartment headings.

Knee: medial; lateral/posterolateral; patellofemoral/extensor; central/intercondylar;
posterior/neurovascular; joint-wide; postoperative when present. Meniscus, cartilage,
bone and stabilisers are adjacent within each regional compartment. Patellar medial
and lateral facets and retinacula stay in the patellofemoral region.

Ankle and elbow use regional compartments; hip uses intra-articular, anterior,
medial, lateral and posterior regions; shoulder groups cuff, biceps, stability,
outlet and articulation; wrist separates dorsal, volar, ulnar and carpal regions.
Other examinations retain authored organs, spaces, vessel territories, sides,
levels or procedural stages as their compartment boundaries. Repeated groups are
made contiguous. Radiographs are included; no cross-modality structure is added.

The compiler preserves all 5,776 rows, descriptor IDs and content, numeric inputs,
follow-up dependencies, exclusion rules, acquisition scopes and calculations.
No observations are inferred from collapse, navigation or unanswered controls.
The prior published catalogue is archived by its hash, so existing pinned drafts
retain their original content and headings. Presentation metadata is available
through the existing form/template REST and MCP responses.

References informing regional organisation:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC11399221/ (ESSR knee MRI recommendations)
- https://radiologyassistant.nl/musculoskeletal/ankle/mri-examination

This is a presentation change, not clinical approval. The exact runtime inverse
covers only the shared JS/CSS so frozen evidence cannot inherit new claims.

# NIH MED_LYMPH_001 source review

Roth, H., Lu, L., Seff, A., Cherry, K. M., Hoffman, J., Wang, S., Liu, J., Turkbey, E., & Summers, R. M. (2015). A new 2.5 D representation for lymph node detection in CT [Data set]. The Cancer Imaging Archive. https://doi.org/10.7937/K9/TCIA.2015.AQIIDCNM

The source requires this additional citation for manual masks: Seff, A., Lu, L., Barbu, A., Roth, H., Shin, H.-C., & Summers, R. M. (2015). Leveraging Mid-Level Semantic Boundary Cues for Automated Lymph Node Detection. Medical Image Computing and Computer-Assisted Intervention – MICCAI 2015, 53–61. https://doi.org/10.1007/978-3-319-24571-3_7

Original CT, DICOM SEG and manual NIfTI masks: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), as recorded on the [TCIA collection page](https://www.cancerimagingarchive.net/collection/ct-lymph-nodes/) and series metadata.

Review derivatives select orthogonal source CT planes, apply original rescale values and display windows, crop without source resampling, and optionally add original mask contours. No stored CT/label values are edited. The figures preserve numeric mask identities and do not assign centroid-annotation IDs, individual-node identity, stations, malignancy or anatomical approval. The supplied 1 mm sampling is verified, while original scanner acquisition thickness remains unverified.

Original archives, DICOM files and full mask arrays remain in ignored research storage. No runtime image, model or fidelity binding is added. Attribution, conversion lineage and scope limits must travel with any later permitted derivative.

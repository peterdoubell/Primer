# Non-traumatic intracranial haemorrhage reporting inventory

The draft identifies 145 named structures, interfaces and findings across 34 groups. Each requires an image, schematic and model. The detailed crosswalk accounts for 31 report rows, including the acquisition and workflow row. Positive examples require case-specific blood, oedema, mass effect, susceptibility or cause evidence.

The [AHA/ASA spontaneous ICH guideline](https://doi.org/10.1161/STR.0000000000000407) informs the acquisition and finding scope. The case map keeps non-traumatic and traumatic investigations distinct. Original volume rights, source labels, actual acquisition coverage and specialist review remain open.

# Six breast reporting inventories

All six breast investigations previously lacked an expanded per-structure image/schematic/3D inventory. The new draft preserves each reader's five report sections, original specific fields and measurement controls while adding actual bilateral tissues, ducts/lobular units, fascia/attachments, neural/vascular/lymphatic routes, individual node basins and lesion interfaces. Implant work additionally separates fill, shell, external capsule, device connections, pocket, displaced material and fluid/mass routes. The 580 groups contain 3,480 parts and 10,440 representation obligations; every actual source component/variant still requires site-specific instantiation and independent review.

Public Radiology Assistant pages were reviewed through the web connector. Direct raw HTML requests returned403 and were not bypassed. The mammography path containing2013 now presents the v2025 article; source path age is not the current page version. The ACR public v2025 article and ultrasound reporting page were acquired and fingerprinted, but the full proprietary manual and blocked Appropriateness Criteria narratives were not retrieved or reconstructed. Older MRI/staging source terminology, cohort percentages and treatment pathways are not asserted as universal current rules.

The original NCI professional page supports separation of clinical/pathological/post-treatment evidence and pectoral from deeper chest-wall involvement. No permissioned staging table is reproduced, no automatic stage is calculated, and the draft does not require whole-body imaging merely to assign a clinical distant-stage category. FDA public ALCL/SCC pages support keeping capsule/fluid/tissue malignancy evidence separate from rupture and device appearance; no source image is reused or current tissue diagnosis inferred.

Official BioC full text for PMC8998991 was acquired. Human descriptive anatomy is used as context; mouse developmental/pathway findings do not supply clinical human anatomy/function. The public original PMC3706056 anatomy/development text was reviewed through the web connector; no permissioned/reprinted embryology figure is reused. Other source intake limitations remain explicit in JSON evidence. Original full source text stays in the ignored research cache; no published source graphics or manual lexicon tables are republished.

Twenty-five preset negative statements are removed because they cannot verify actual examination coverage or source findings. Source morphology, kinetics, ADC, Doppler, device shape, breast sex/population or one-sided schematic geometry do not establish every current tissue, histology, stage or physiology. Existing media bytes and clinical/anatomical approval remain unchanged. The current single-left-breast schematic remains only orientation, with bilateral native and microscopic coverage explicitly unverified.

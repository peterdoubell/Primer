Source identity and review limits

Original v1 metadata: age 60, female, institute C, neck/thorax/abdomen/pelvis CT, training split. The dataset supplies a 299 × 299 × 394 grid with published 1.5 mm pitch after dataset resampling. This is not raw scanner DICOM. The NIfTI physical-units code is unspecified; source axes and values do not independently establish patient orientation or HU calibration. Diagnosis, contrast phase, cardiac phase and normal-atlas approval remain unspecified.

The original label name heart_myocardium is retained. Published cardiac methods describe the output as LV myocardium. The four separate chamber-region labels do not establish complete blood pools, RV or atrial walls, fine valve planes, appendages, valves, pericardium or full reportable anatomy. Each surface is a complete 0.5 interface of its unchanged binary source mask. Area-weighted display normals are derived from retained source triangles. No smoothing, fitting, padding, capping, component deletion or mesh repair is applied.

The current v3 s0028 CT has the same grid and affine, but differs in 11,945 samples outside these five original cardiac labels. This viewer preserves the distinct v1 image and metadata. It supplies no current-patient registration, quantitative function, clinical completeness or clinical approval.

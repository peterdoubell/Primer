# Original BodyParts3D peripheral source collection

Seventy complete original OBJ objects were retained from the first-party version4.3 selector, representing 55 source ontology concepts in its lower-limb systemic-circulation collection. This grouping also includes adjacent epigastric/genital branches; they are retained as source-labelled objects, not reinterpreted as foot arteries. Original OBJ bytes are stored in lossless gzip containers with separate compressed-file and original-byte hashes; the complete source text, including whitespace, is recoverable exactly. Exact native coordinates, normals, indices, source headers, is-a/part-of mapping rows and licence evidence are preserved. The strict acquisition helper rejected **FJ2127**: the requested catalogue maps it to **FMA20796 / Right deep femoral artery**, while the returned member and OBJ header identify **FMA20731 / Trunk of right femoral artery** and BP23446. The catalogue's original OBJ filename additionally says **perforating arteries of the left thigh**. This is not silently resolved through relabelling, lateral mirroring or a replacement anatomy claim. The whole original object is preserved as evidence and excluded from confident identity/display binding. Other matches establish source identifier agreement, not independent anatomical accuracy or patient laterality.

All70 objects were decoded and checked: **278,094 original triangles** retained, valid original indices and finite coordinates/normals, no zero-area triangles observed. Exact-coincident-position topology analysis has no boundary/nonmanifold edges, but that is analysis only—source vertices were not welded or repaired. Closed source objects do **not** prove continuous branch lumens, arterial wall thickness/volume or physiological flow. Header/source bounds differ by up to 0.3872 source-declared mm; both are retained without fit/repair, and independent physical calibration, original acquisition/resolution and self-intersection/interface review remain unverified.

The scientific context sheet shows all69 identifier-matched source objects and all25 selected foot-labelled objects, using complete original triangles in original axes. FJ2127 is excluded. No source rescaling, synthetic extension, native MRI registration/fusion, patient pathology or native full reporting-tree claim was applied. A source catalogue “trunk of femoral artery” is not automatic individually segmented common/superficial femoral anatomy, and these objects do not complete all 945 peripheral MRA leaves.

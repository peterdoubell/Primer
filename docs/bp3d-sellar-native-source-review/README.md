# Original sellar source surfaces, with explicit alternatives and an identity hold

The versioned upstream BodyParts3D4.3 manifest genuinely supplies eight requested FMA concepts through thirteen original source objects. The full native OBJ ZIP was acquired through the official versioned download API. Every requested object, actual returned header, source face/normal/index record and ZIP CRC was checked. There are19,112 original triangles. The source OBJ bytes remain independently preserved, including the held object; no image screenshot is converted into biological geometry.

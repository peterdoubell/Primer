# Original traumatic haemorrhage sources

This package preserves the complete published CENTER-TBI artwork and a newer NINDS reporting source. It supplies licensed teaching examples and reporting context. Clinical approval, complete fine-structure coverage, patient registration and source-native lesion meshes remain unestablished.

Vande Vyvere and colleagues' [2024 CENTER-TBI pictorial review](https://doi.org/10.1089/neu.2023.0553) is a 50-page publication with an explicit CC BY 4.0 grant on page 1. The unchanged publication was acquired from the authors' institution, [Monash University](https://researchmgt.monash.edu/ws/portalfiles/portal/660520113/659672588-oa.pdf). All 14 numbered main figures are retained. Figure 2 contains two distinct complete image objects, so the package has 15 original encoded JPEG streams and 15 lossless display PNGs. No original panel is removed to fit a deployment limit.

The original PDF, encoded streams and display PNGs total **24,471,521 bytes**. The displayed objects contain **40,936,483 native RGB pixels**. The five clinical artwork objects contain 67 source-labelled views: 63 CT views and four MRI views. Three CT views are published static skull volume renderings. They do not supply an acquired volume or a reconstructable mesh. The other ten artwork objects are cohort statistical plots.

The source PDF uses untagged DeviceCMYK, or DeviceGray for Figure 12, without an embedded ICC profile or output intent. Its raw DCT streams are retained exactly. Treating the DeviceCMYK streams as ordinary standalone JPEGs in a generic decoder produced dark/inappropriate colours during inspection. Display PNGs therefore use MuPDF's declared PDF colour-space interpretation at the original object dimensions. This is a colour conversion, recorded as such; no pixel geometry is cropped, resampled, painted, sharpened or relabelled. The complete unchanged PDF preserves the original channels, vectors, captions, typography and page context. This review does not claim independently calibrated colour or equality of RGB values to CMYK source channels.

The actual effective catalogue was inspected through `Curriculum` and `radiology_catalog.detail` before source integration. Its complete reporting fields, template, reading assignment and walkthrough are retained in `effective-reporting-scope-before-integration.json`. The following mapping identifies local source examples, rather than granting full reporting coverage.

The [2025 NINDS imaging working-group recommendations](https://pmc.ncbi.nlm.nih.gov/articles/PMC12409119/) and their original illustrated common-data-element appendix supply updated definitions. Their XML, PDF, proposed-template JPEG and DOCX match the original NCBI-cloud publisher MD5 values. Three unchanged public context documents total **14,403,832 bytes**. The native DOCX retains all 28 media entries, including repeated artwork; 26 unique artwork digests are not 26 independently validated cases.

The appendix credits the NIH-funded TRACK-TBI study and Massachusetts General Hospital teaching files for scalp/penetrating exemplars. Its revised pseudoaneurysm image credits [Palmieri and colleagues](https://doi.org/10.1007/s10143-021-01657-4). The original donor article's current XML explicitly includes images under CC BY 4.0 unless a contrary credit says otherwise; no excluded credit was found for the cited figure. The appendix image retains the later C/D CTA pair and a source-added caption, with the donor first-admission A/B pair omitted by that source revision. Primer preserves the revised appendix without altering it. Source Office-generated accessibility descriptions are not accepted as clinical captions or evidence that the underlying medical image is synthetic. TRACK-TBI and CENTER-TBI cases are kept separate.

All 34 public files together total **38,875,353 bytes**. Source acquisition duplicates and original XML metadata are evidence files, distinct from this public-media total. No source is downsampled for deployment. Root integration may deliver these exact registered files through pinned object storage.

The source packager uses fixed trusted source paths and destinations. It creates proposals only and does not edit the runtime registry, curriculum, reporting template, source geometry, production database or approvals. Thirteen source tests verify the complete objects, exact encoded streams and document bytes, native-dimension colour interpretation, 67 panel roles, temporal/case relationships, complete DOCX media and attribution, and rejection of false modality/coverage/rights claims. A fresh isolated Chromium context decoded all 15 display PNGs; every native RGB pixel matched the declared PDF interpreter and no browser errors occurred. This is standalone source-display evidence, separate from authenticated reader, Blob delivery or production testing.

The 2024 publisher lists 52 additional DOCX supplements. Publisher HTML and supplemental-file fetches returned HTTP 403 to this runtime; those supplements and independent higher-resolution publisher masters were not acquired. They remain explicit acquisition gaps. The 2025 appendix does not retroactively substitute for missing 2024 supplement bytes. Original DICOM stacks, calibrated HU/pixel spacing, full fine boundaries, patient-specific segmentations/meshes and independent clinical review are still required before complete reporting fidelity can be claimed.

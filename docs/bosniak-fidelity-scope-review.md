# Cystic renal-mass fidelity requirements and source-qualified prompts

The Bosniak reporting investigation now has 163 draft anatomy/feature targets, each requiring separate image, schematic and model evidence (489 representation obligations). Its effective checklist, template sections, walkthrough, reading and classification contract are fingerprinted. Whole acquired renal localisation and observation margins remain separate from complete wall surfaces, every actual septum/attachment and every actual nodule/attachment interface. The draft is an expansion index; each source feature still requires explicit instance identity, actual whole extent and specialist review.

Native resolution and uncertainty must support the particular thickness/size/margin claim. A generic cyst shell cannot supply septa, nodules, enhancement or MRI tissue characteristics. A cut through one connected septum is not a second septum. MRI-only T1/T2/subtraction exceptions cannot borrow CT imagery. Static normal renal geometry cannot supply positive cystic wall/protrusion features. Full prior/current correspondence, technical limitations and actual eligibility remain required; stable size alone is not complete stable morphology.

The [Silverman et al. v2019 consensus](https://pubs.rsna.org/doi/10.1148/radiol.2019182646) was reviewed against the existing [Radiology Assistant reading](https://radiologyassistant.nl/abdomen/kidney/bozniak-2019). The IIF walkthrough now makes enhancement explicit for the four-or-more-thin-septa option and includes minimally thickened smooth enhancing septa. Enhancement prompts distinguish visible from quantitative confirmation and require matched technique; the ≥70 HU benign pattern specifies unenhanced CT. MRI heterogeneous unenhanced fat-suppressed T1 IIF context is retained separately from III/IV features. Known hereditary RCC context is kept outside routine general-population applicability. These are source-qualified reporting prompts, not an automatic category/pathology/management algorithm. No source figures were copied or rights inferred from scholarly access.

The inventory separates thin-feature guideposts from actual measured regions, source calcification/contents from hidden enhancement, nodule acute/obtuse interfaces from generic shapes, and eligible cystic masses from infectious/inflammatory, vascular and necrotic solid mimics. No CPTAC malignant ROI or held liver/renal model is relabelled as a verified Bosniak cyst. Appropriate phase, source morphology and clinical context remain unapproved.

Five new Bosniak regression checks and 50 combined renal/scope/walkthrough/reporting checks passed. They retain current source contracts, reject parent-shell/normal-anatomy coverage of positive fine features and preserve MRI-only evidence requirements and qualified prompts. Desktop/mobile source QA confirmed the corrected text, no horizontal document overflow and no browser runtime errors; owned browser/server sessions were closed. This is a local change after PR #63.

The known all-radiology floor is now 11,640 representation obligations. There are 105 unexpanded investigations, and all 106 curriculum surfaces still require reconciliation. The full denominator is unknown, no new representation is clinically approved and complete commercial/clinical readiness remains unproven.

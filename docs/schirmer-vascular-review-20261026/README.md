# Matched vascular study-template reference

This reference adds the released Schirmer study-template T1, T2 and FLAIR volumes, original numeric regions, native-label schematics and exact source-cell meshes to the brain-anatomy and acute-stroke readers. It retains all eleven nonzero values and all fifteen 26-connected components. Ten values have names derived from the primary publication's Figure 1. The extra value 19 is one preserved, uninterpreted voxel.

The source is Zenodo record 3379848, version 1.0.0, explicitly licensed CC BY 4.0. The publisher also licenses the paper and Figure 1 under CC BY 4.0. Original files and publisher checksums are retained for reproduction, while deployed runtime assets use lossless plane packs and cell-boundary geometry. Attribution identifies the authors, source URLs, licence and Primer derivations. Four source files are used: the label map and the full T1, T2 and FLAIR templates; the separately supplied brain-extracted/intensity-normalized FLAIR is not substituted for the full FLAIR.

The template combines sixteen older adults, twelve with cerebral amyloid angiopathy and four controls. The authors processed, smoothed and registered the template to MNI space. Its released 1 mm grid differs from some acquisition resolutions. Coordinates and displayed region volumes describe this template space. The source is a reference separate from the clinical case, not a current-patient registration or a normal-population atlas.

Names are transcribed from the publication legend and associated with numeric values by figure correspondence; no author-supplied numeric lookup table was found. An independent direct-index sampler verified 69,328 stable interior pixels with zero background or wrong-label matches. Forty-eight negative controls detected orientation, plane and label-swap errors. The full classified figure includes 677 boundary/background disagreements out of 94,652 pixels, so exact published-figure boundary identity is not claimed. Runtime geometry and image transport instead preserve the original released arrays. Pons/medulla remains a combined source region. Cerebellar regions do not define lobules, nuclei or individual cerebellar arterial territories; ACA/MCA/PCA masks are parenchymal territories, not vessel-lumen or MCA-division models. No individual fine-structure coverage or clinical approval is granted by this reference.

Independent checks compare all 2,328 decoded planes (86,652,384 source samples), every exposed source face and all 754,024 triangles. The actual authenticated reader exercises 286 display states at phone and desktop widths, original GPU buffers, all component foci, physical scale bars, both lesson mounts, camera controls and recovery from corrupt or stale responses. It performs no production learner writes. Original NIfTIs remain in Git for reproducibility and are excluded from the deployment payload. Source-input checks, runtime metadata checks and actual hosted delivery checks are separate gates.

The full radiology, mathematics and physics objective remains incomplete. This source adds named, traceable regional reference anatomy without treating its presence as proof that every reportable structure has an adequate image, schematic and model.

# Hip imaging — femoroacetabular impingement

Investigation: `ra.hip-fai`

## Reporting obligations

- **Femoral Morphology:** Assess head-neck sphericity and cam morphology at the relevant clock-face location.
- **Acetabular Coverage:** Assess lateral coverage and version in the context of pelvic position.
- **Labrum — if MRI acquired:** If MRI or MR arthrography was acquired, localise tearing, detachment and paralabral cysts. Otherwise state that the labrum is not assessed.
- **Joint space and cartilage:** Describe radiographic joint-space loss and subchondral change; map cartilage lesions only if MRI was acquired.
- **Alternative Pain Generators:** Assess additional bone/joint abnormalities on the acquired radiographs. If MRI was acquired, also assess periarticular tendons, bursae, muscles and covered pelvic structures; state limitations of coverage.

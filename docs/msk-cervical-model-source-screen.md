# Cervical ligament dataset screening

27 September 2026. This bounded source pass sought actual reusable ligament
surfaces independently of the pending UCSF/Sketchfab rights inquiry.

## Wang et al. 2019

[Primary full text](https://onlinelibrary.wiley.com/doi/full/10.1111/os.12474):
*Establishment and Finite Element Analysis of a Three-dimensional Dynamic Model
of Upper Cervical Spine Instability*, Orthopaedic Surgery 11:500–509.
The publisher's Ligamentous Selection and Material Assignment sections describe
nonlinear spring elements for most ligaments. The transverse ligament is an
exception: a solid hexahedral representation derived from anatomical parameters.
That is not evidence of segmented patient-specific ligament surfaces. A large
element count does not establish anatomical detail.

No mesh download, supporting-information package or data-availability link was
identified in the inspected full text. This records the inspected article, not
proof that files do not exist elsewhere. No mesh was acquired, no anatomical
claim promoted and no new author inquiry sent. The article's open-access grant
does not by itself establish rights to an unavailable external model file.
No published biomechanical stress, diagnostic or treatment claims were imported.

# Offline reporting material in the Vercel bundle

The Python builder excludes the plain reporting catalogue, historical catalogue snapshots and offline fidelity inventories and audits. The reader uses the gzip catalogue. The effective exclusion from the deployed function also depends on which files Vercel's Git integration supplies to the builder.

The plain catalogue is 79,456,460 bytes. Its gzip counterpart decompresses to identical bytes and contains all 98 report forms. The authoring copies remain in Git.

The cross-topic scope-review document remains available to the reader for runtime validation. The historical configuration inverse is pinned to the exact bytes.

# Percentage workbench

This release replaces the `math.2.percent` generic activity with six exact rational investigations: percent of an amount, conversion, part/whole, percentage change, successive changes, and mixed-format discounts. It retains all ten original assessment objects, prerequisites and the original illustration. Thirteen presets cover the assessed examples and fractional, recurring and zero-base cases.

The hundred-grid shades a partial cell for fractional percentages. Amount bars use a common scale derived from the accepted state; successive-change ledgers identify each immediate base. Exact fractions remain fractions when their decimal expansions do not terminate. Display coordinates use floating point; displayed algebraic equalities use reduced rational values. Amounts are mathematical divisible quantities; results are not silently rounded to currency cents or whole objects. The separate rotatable disk has independent controls.

`tools/check_percentage_core.py` uses Python Fraction as an independent oracle. The actual reader check uses isolated synthetic loopback data, verifies served bytes, original assessments and illustration, full speech, invalid-draft recovery, keyboard scrolling and geometry at phone and desktop widths. It performs no production learner writes. `runtime-inverse.json` records exact shared-file deltas so historical evidence remains tied to its original bytes; it grants no new approval.

This is one mathematics lesson improvement. It does not establish clinical approval or completion of the whole Primer visual-fidelity goal. The alternative vascular source remains research and is not included in this release.

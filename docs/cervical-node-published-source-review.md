# Original nodal CT comparison with source pathology outcomes

Original Figure 5 from [Henson et al., Diagnostic challenges and prognostic implications of extranodal extension](https://pmc.ncbi.nlm.nih.gov/articles/PMC10548228/) is preserved as a two-patient comparison. The actual article CC BY4 grant names co-author James Bates as a copyright holder; the caption credits him as the image provider. That explicit owner/grant/credit match is retained. Figures 1–4 remain held because BioRender or non-author third-party credits need separate scope review. No blanket grant is assumed for those materials.

The source captions describe contrasted axial CT: panel A is a left level II node suspicious for imaging ENE, later confirmed pathologically; panel B is a different right level II suspicious node without ENE on pathology. These are publication outcomes, not independent pathology readout or a rule distinguishing positive/negative pENE from appearance alone. No patient age, sex, assay category, vessel flow, full native extent or universal grading/staging system is invented.

The original publisher PDF passed its MD5. The 1832×1094 embedded image object 91 supplies a larger master than the web image. Extracted RGB samples equal the original PDF object samples exactly; its original ICC profile is preserved without pixel changes. The full image and labels were visually inspected, and numbered web/PDF identity checked (diagnostic low-resolution RGB RMS approximately 0.342). This comparison is figure binding, not clinical accuracy or patient measurement.

Complete original captions, author/DOI attribution, provider credit, source pointers and grant are attached. All structure coverage remains empty with pending anatomical review. A selected CT pair does not establish every node/capsule/neck-level boundary, microscopic extension, vascular invasion, function or full native 3D model. Replaced investigation media are archived; other lessons and investigations are unchanged.

# Native cervical-node source review

The objective remains all reported structures in all radiology modules, faithfully represented in images, schematics and 3D. This source audit does not close cervical-node coverage.

The author-linked [LNCTVSeg repository](https://github.com/Luoxd1996/LNCTVSeg) provides an original paired CT example and six annotated target regions. All five published example blobs match their GitHub blob hashes. Independent custom and nibabel readers agree on all 157,286,400 scalar samples, the original grids and affine transforms. The three arrays are 512 × 512 × 200, with declared 1.337890625 × 1.337890625 × 3 mm sampling. The CT arrays differ; the same declared grid does not prove independent DICOM registration or HU calibration. Source readme roles are noncontrast and contrast-enhanced CT; individual contrast phase, timing and patient metadata are unavailable.

All six original regions are retained, each with one six-neighbour component. Their unchanged binary-mask 0.5 isosurfaces contain 66,144 triangles in total, using only the original sform. No padding, fitting, smoothing, decimation, class merging or component deletion was performed. Closed target-region surfaces do not establish anatomical node capsules. The surfaces and native CT review plate remain in the ignored acquisition cache, with hashes in the committed audit. The plate shows original indices 94, 115 and 123, using the same display window for both CTs, with exact source-label contours; it was visually inspected. No source samples are resampled.

The [primary paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC11452638/) distinguishes the actual Figshare dataset's CC BY 4.0 grant from its own CC BY-NC-ND 4.0 article licence. Its target boundaries are modified for NPC radiotherapy and are not a universal surgical map. The repository calls labels 3/4 IV+Vb, while article Table 2 includes IV+Vb+Vc; this semantic discrepancy is unresolved. Combined masks cannot supply independent II/III/V sublevels or individual nodes, cortex, hilum, capsule, ENE, gland, vessel-wall or neural anatomy. Blurred facial regions are source processing, not intact native head anatomy. Sampling is inadequate to assert every tiny reported structure.

The actual [Figshare v3 dataset record](https://doi.org/10.6084/m9.figshare.26793622.v3) grants CC BY 4.0. Its complete 2,151,914,296-byte archive has publisher MD5 `5cb2ed3a1f57f43e849e19cf8c755169`, but has not been downloaded or independently verified. Correspondence of the repository example to that archive has not been established; the repository software GPL-3.0 licence does not itself prove the example's data grant. No example image or surface is published in the runtime, and no anatomical or clinical coverage is granted.

Other primary candidates remain distinct: [RPA Head and Neck Lymph Nodes](https://www.cancerimagingarchive.net/collection/rpa-head-and-neck-lymph-nodes/) and [HEAD-NECK-CT-ATLAS](https://www.cancerimagingarchive.net/analysis-result/head-neck-ct-atlas/) currently place imaging/RTSTRUCT under NIH Controlled Data Access; their open spreadsheet licences do not clear those images. No controlled image download was attempted. [HNTSMRG training data](https://zenodo.org/records/11199559) are CC BY-NC 4.0. The [HECKTOR 2026 record](https://zenodo.org/records/19726369) inspected contains a proposal PDF, not licensed native images. None supplies commercial image clearance by inference.

Next acquisition must establish an actual native-data grant and preserve case-specific tissues. The missing node internals and adjacent interfaces remain required; target-region surfaces will not be substituted for them.

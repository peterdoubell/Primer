# CMHA MCA bifurcation aneurysm

The [CMHA dataset](https://doi.org/10.6084/m9.figshare.26965450) by Miao Song and colleagues provides the CTA and two original surfaces for AHMU1218005 under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The clinical table records rupture and an M1–M2 junction location. See the [data descriptor](https://doi.org/10.1038/s41597-024-04056-8) for the acquisition and modelling methods.

All 561 sections retain the numerical values of the released NIfTI. Every finite source value is exactly representable as a signed 16-bit integer. The browser reverses the anterior-posterior row order for an anterior-up display. The surface payloads preserve the order and winding of the original 2,598 sac and 11,820 combined triangles.

An LPS-to-RAS conversion gave the highest median interpolated intensity at the triangle centres of both meshes among the eight possible axis-sign combinations. The included three-plane render shows the corresponding intersections. Independent alignment review and individual branch identification are pending. The paired package contains CTA and surfaces. Use the separate RHUH case to explore a binary haemorrhage mask.

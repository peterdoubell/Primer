# Original esophageal native context acquisition and review

[TotalSegmentator v3](https://zenodo.org/records/22688904), case s0358, provides a whole source CT and selected 27 same-case organ/context masks. The acquired objects retain their original ZIP member CRCs and local SHA256s. The publisher archive size/checksum matched before/after acquisition. The whole 37.4 GB archive MD5 remains unverified; no HTTP entity tag was supplied. The original dataset metadata grants CC BY 4.0. Attribution: Jakob Wasserthal, TotalSegmentator dataset v3.0.0, DOI 10.5281/zenodo.22688904; source interface extraction is an adaptation, with no endorsement implied.

The complete CT and every selected mask were independently decoded using the custom NIfTI reader and nibabel: all 952,226,100 stored samples and original affines agree. The source grid is 255×255×523 with declared 1.5 mm pitch and RAS sform. This proves declared-grid correspondence, not independently verified raw DICOM geometry, HU calibration, fine-tissue accuracy or patient registration. Public source metadata describes a 90-year-old female, trauma/abdomen, study type ct pelvis; this is not a normal dedicated esophageal study.

All 686,252 original derived triangles are retained after 0.5 Lewiner extraction with only the original sform. No smoothing, capping, padding, decimation, fitted transformation, class merging or removal of original components was applied. Float64 positions and uint32 faces are preserved with decoded hashes. All surfaces are finite with no degenerate triangles or nonmanifold edges; the spinal-cord boundary remains open with 40 edges at the source scan extent. Binary-field residuals up to 0.125 arise at ambiguity-resolution vertices; these are not distances or proven anatomical error.

All 27 complete surfaces were rendered and visually reviewed across three sheets. Component-orientation-review.json distinguishes mask foreground components from oriented surface interfaces. Heart mask has 2 six-connected components and 47 surface components; 45 are opposite-winding to the largest, so surface count alone does not imply 47 organ fragments. Left upper lobe has 261 six-connected mask components and 137 surfaces; its source assignment remains unresolved. Pulmonary veins preserve 4 disconnected components. T6,T8,T11 and lower lung extra components remain. No source defects were hidden or repaired.

This is a source-faithful candidate bank for a matching CT/3D context viewer. It remains held from the runtime registry pending source-plane and teaching suitability review. One esophageal class cannot supply separately reported lumen, mucosal layers, glands, neural/vascular/lymphatic plexuses, hiatal attachments or every lesion. Whole heart and atrial appendage do not separately establish left atrium. The full reporting inventory and fine tissue/source validation requirements remain unchanged; no anatomical requirement coverage or clinical approval has been granted.

Matching original full CT/mask axial source planes 373,385,415 were reviewed for nonlargest left-upper-lobe components. The largest foreground component has 282,502 voxels, with 1,329 voxels elsewhere. Source plane hashes and counts are retained separately; display uses source-value window -160..240, nearest-pixel display and declared 0.5 contour interfaces. Original source bytes and mask samples remain unchanged. Source left/right names have not been independently verified against original DICOM orientation, and the source assignment/cause remains unresolved. These labels are held from the runtime registry.

A dedicated source-inspection reader is now prepared after mesh/array transport and local mobile UI checks. This permits direct comparison with the complete original CT and all27 reversible mask bits; it does not remove any source-assignment or anatomical approval hold above. Inspection-integration-review.json records this distinction from the original acquisition-time runtime flags. All clinical/anatomical requirement coverage remains unapproved.

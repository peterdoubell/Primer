# Complete source CT connected to the partial native meshes

The thyroid 3D reference links to the complete s0358 CT acquisition and its eight original binary annotation masks. Selecting a registered model part updates the link to that exact source label. The viewer starts at that label's original source bounds centre but keeps every slice of the entire original 255×255×523 grid available. No extra ROI crop, resampling, interpolation of stored samples, fitted registration, relabelling or boundary repair is introduced.

All 34,008,075 signed-int16 CT samples remain in original NIfTI voxel order, x fastest then y then z. CT payload SHA256 agrees with the independently decoded original native-source review. Eight one-bit masks are packed into reversible bits of a byte, not merged into an exclusive class map. Every reconstructed mask SHA256 and foreground count matches its original; 22 overlapping source voxels retain every original class. The persisted HTML payload was read back and verified independently. The browser checks decoded SHA256 and array lengths before enabling display.

Three source index planes, every native slice index, source-value window controls and an optional selected-label cyan overlay support inspection. Display pixels are mapped from original signed-int16 source samples using the selected window; illustrative overlay colour is separate from stored data. Source RAS coordinates come only from the original sform. Native DICOM/patient orientation, HU calibration, contrast phase and effective fine-wall resolution remain unverified. The source metadata remains age 90.00/female and ct pelvis/trauma/abdomen. CT and labels do not establish ultrasound echogenicity/Doppler, functional findings, tissue identity or the patient being reported.

Local browser review confirmed rendering in all three source planes. Independent original-file centre values (-66 at [127,127,494], 82 at [118,127,261], and -29 at [127,135,261]) matched the browser. Slice control reached source k=0 and k=522. Desktop and mobile source/overlay images were inspected; stair steps, annotation discontinuities and acquired boundaries remain. The thyroid 3D selection updated the source link to `?level=thyroid%20gland`. No browser errors were reported. This verifies software/display correspondence, not every anatomical boundary.

The original dataset CC BY4 grant and attribution are preserved. The viewer adaptation comprises exact CT payload transport, reversible mask-bit packing, source-value window display and illustrative overlays. Individual source member CRCs and local hashes were verified; full archive MD5 and independent source object immutability remain unverified. No source model or clinical image gains anatomical requirement coverage.

The same registered static HTML delivery used by the existing VerSe CT viewer now includes this source. The original app path remains access-controlled; registered hosted requests redirect to the static CDN. Manifest and renderer hashes are validated with their source-to-part selection mapping. Seventy-two source, hosting and integrity tests passed before release checks. The full radiology fidelity gate remains incomplete, including 62 investigations requiring full structure expansion. Independent fine thyroid/nodule/parathyroid/nerve/node/vessel-wall and lesion/interface coverage is still missing.

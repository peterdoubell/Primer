# Original expert structural tumour source: ISPY1_1002

The primary [TCIA expert dataset](https://www.cancerimagingarchive.net/analysis-result/ispy1-tumor-seg-radiomics/) grants CC BY 3.0 and identifies manually revised structural tumour volume (STV) annotations reviewed by a board-certified,fellowship-trained breast radiologist. DOI 10.7937/TCIA.XC7A-QT20; attribution: Chitalia,R.,Pati,S.,Bhalerao,M.,Thakur,S.,Jahani,N.,Belenky,J.V.,McDonald,E.S.,Gibbs,J.,Newitt,D.,Hylton,N.,Kontos,D.,and Bakas,S. Original data were retrieved from the public TCIA package using IBM's official task-local command client. No system application/browser extension was installed. No source transfer credentials or client runtime are included in repository artifacts.

All nine complete source files match the original publisher MD5 manifest, retained alongside local SHA256s. They comprise manual STV,computed STV,functional tumour volume (FTV),three bias-corrected MRI acquisitions and three producer-resampled/z-scored MRI acquisitions. All 39,728,640 stored samples and original transforms match independent direct NIfTI-header/payload and nibabel decoding. The manual mask and all three processed MRI grids exactly agree at 200×200×120,declared 1 mm pitch,with qform-only geometry. Original bias-corrected images/FTV use 256×256×60 at 0.78125×0.78125×2mm; no hidden fit merges these grids.

The original [dataset paper](https://doi.org/10.1038/s41597-022-01555-4) and README describe N3 bias correction, 1 mm isotropic resampling and instance-level z-scoring across the three timepoints. Those processing operations are producer history,not new clinical acquisition resolution or independently measured physiology. Original processed float32 values and source qforms/sforms are preserved; no actor-side voxel resampling,clipping,cropping,label repair or class merging occurs. Source phase indices do not supply independently verified injection clocks or raw patient registration.

Full 0.5 label-interface extraction retains both manual components and all 5,144 triangles,including the 44-triangle component. Functional source retains 14 surface components / 7,058 triangles; computed prediction retains 19 components / 8,304 triangles. Manual/computed original-grid Dice is 0.7690207085; the computation is not substituted for expert annotation. Boundaries,internal shapes and all original components remain. No smoothing,capping,padding,decimation or fitted registration is applied. Binary-field residuals are not anatomical distances or clinical accuracy measurements.

Every source surface and matching complete processed MRI planes were visually reviewed. This verifies source correspondence and transport preparation; it does not approve every breast skin,gland,duct,fascial,neurovascular,nodal,lesion or device structure. Source roles,tissue identity,raw acquired DICOM correspondence and current clinical interpretation remain separate. This bank is prepared for scope-labelled reference integration; no runtime or full clinical/anatomical approval is granted here.

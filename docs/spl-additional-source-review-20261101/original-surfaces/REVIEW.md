# Additional SPL original surfaces and exact-cell candidates

All 94 additional publisher-named raw label classes now have acquired original VTK surfaces, verified by byte count and pinned Git blob SHA-1. Their 232,954 vertices and 449,222 implied strip triangles are preserved, with normals and strip primitives retained. All original components are kept. The legacy Slicer4.4 scene passes VTK polydata through in RAS millimetres; no modern unmarked-VTK LPS flip is applied. The five optic-pathway VTK4 files use the same validated binary points/strips/normals layout; the parser accepts both observed versions without altering the input.

Index-based boundary edges occur in 93 surfaces, and exact coordinate-coincidence analysis finds no unmatched geometric boundary edges. 29 surfaces have higher edge incidence under exact coordinate coincidence; those source contacts are retained for qualification. No zero-area triangles were observed. Coordinate grouping is analysis only: the packaged meshes are not welded or repaired. A separate exact-cell build for the same 94 codes retains all source exposed faces and components, totalling 298,878 vertices and 599,136 triangles. This source-grid geometry is not independently validated biological anatomy.

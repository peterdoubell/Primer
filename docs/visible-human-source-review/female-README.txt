README FILE - Female README

IMAGE DATA:
Image Files within the subdirectories contain 2 dimensional views
of a female cadaver, as collected for the National Library of
Medicine's Visible Human Program.  Image data usage is approved in
accordance with the conditions as stated in the NLM Terms and Conditions at
https://www.nlm.nih.gov/databases/download/terms_and_conditions.html

The image subdirectories are:

	Fullcolor.......contains 24 bit full color cross sections
	                by anatomical areas

	Radiological....contains CT and MRI sections

	utils...........contains binaries for uncompressing files

Files:
	INDEX...........List of directories and files
	INDEX.Z.........Above list compressed

Change directory (cd) to copy images(i.e. cd Fullcolor)

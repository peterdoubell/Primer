README FILE - Female Fullcolor

 IMAGE DATA:  
 Image files within this directory contain 2 dimensional views of a female 
 cadaver, as collected for the National Library of Medicine's Visible Human 
 Program.  Image data usage is approved in accordance with the conditions 
 as stated in the written license agreement.

Anatomical Area:  HEAD, THORAX, ABDOMEN, PELVIS, THIGHS, LEGS, FULLBODY
   The body region. Overlap images are included.
 
Type image:  COLOR BIT MAPPED
  Specifies the image capture medium. 
 
Frame size:  2048,1216      
  Specifies the image size (width, height) in pixels.
 
Pixel size: .33mm,.33mm, .33mm
  Specifies the pixel size (width, height, separation) in millimeters.
 
Image format:  RGB 24 BIT NON INTERLEAVED, COMPRESSED.
  Unix compressed, use "uncompress [filename]" to restore.
 
Header size: NONE      
  The header block size in bytes.
 
Coordinate offset:  NONE,NONE      
  If images files are cropped to remove empty pixels, these offsets
  are provided, in pixels, relative to a fixed coordinate plane.

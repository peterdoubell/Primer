# Temporal and ventricular source context for epilepsy

The epilepsy lesson and reporting model tab now offer a focused view of 18 original SPL classes: bilateral lateral ventricular spaces, temporal horns, whole source white matter, and six pairs of temporal parcels. The viewer initially compares source classes 4 and 43. All other existing relationship groups remain available. This makes those native images and 3D source objects directly accessible from epilepsy, rather than treating the earlier twelve limbic classes as sufficient context for every reporting field.

No anatomical payload is created or changed. The new manifest preserves all 217 source label records, mesh descriptors, MRI/label affines, sample identities, retained components and face-provenance records. It replaces the source-only orientation activity with the focused context group and sets a valid initial comparison code. The common renderer accepts that optional source code; the original brain reader retains its existing default and source manifest. The new virtual manifest is served from a pinned gzip file. Mesh requests redirect to the original protected source route; shared native MRI and label requests use the existing limbic source. Required source notices and full terms remain linked to the original package.

The new view supplies source context, not clinical adequacy. Ventricular-space classes do not separately segment ependymal layers. Temporal-pole classes do not provide the adjacent skull-base floor or establish an encephalocele. Temporal parcels and whole white matter do not establish all cortical/sulcal anatomy, cortical thickness, biological grey–white borders, a transmantle lesion or tract connectivity. Source-label names are retained. No source region is split into invented fine structures, and no source case is registered to another case or to the current patient.

`requirement-source-granularity.json` retains the twelve bilateral draft requirements, their 22 required parts and six broader contract groups. It keeps whole hippocampal classes separate from independently verified head/body/tail architecture. HippUnfold dark-band/endpoint classes remain partial context; its HATA class is not a whole amygdala. Dryad's combined DG/CA4, CA2/3 and pre/parasubiculum annotations remain combined and are not automatically assigned to either required side. These are source-grain statements, rather than anatomical approval or a completed reporting inventory. The effective reporting contract and the previously reviewed [ILAE MRI consensus](https://www.ilae.org/guidelines/guidelines-and-reports/recommendations-for-the-use-of-structural-magnetic-resonance-imaging-in-the-care-of-patients-with-epilepsy) retain their broader scope.

The actual authenticated synthetic lesson and reporting model entry points pass at 390 and 1440 CSS pixels. All 480 native MRI states match independently reconstructed source pixels: 34,979,840 pixels, with pair/group/unmarked overlays. All 18 loaded GPU position, index and world-position buffers match their original identities. Four camera views per mount retain the complete source geometry in the fitted frustum. Default selections and close/reopen states are checked. Legacy external reference-image requests are blocked and recorded; their delivery, rights and fidelity are not established by this check. No production learner data is written, and authenticated production operation is not claimed.

Historical evidence is unchanged. A pinned, literal reversal recovers exactly the merged PR192 runtime and removes only the exact new epilepsy descriptor. It rejects unrelated byte changes, duplicate bindings and approval drift. Earlier proofs retain their original experiment and scope. The initial full local run returned 37,096 passes, three failures and 39 skips. The saved descriptor and bounded historical source checks were corrected; all 37 affected tests now pass. Fresh complete CI and staged release checks remain required. The overall radiology and math/physics objective remains incomplete.

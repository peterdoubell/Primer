When the superconducting state ends

Ideal bulk type-I teaching model: negligible demagnetization, fixed Tc = 7.2 K and μ₀Hc(0) = 80 mT. This is not a microscopic prediction for a real specimen.

Scroll the plot horizontally to inspect the full 0–10 K range. “Inspect transition” centers the boundary when it exists.

The gold branch ends at its superconducting one-sided limit. The blue branch is the normal state. Open endpoints at nonzero field indicate coexistence; no sloped line joins the jump and no unique homogeneous order is assigned at that point. The order index √(1−T/Tc) is phenomenological, not a measured energy gap. Finite-sample intermediate domains, surface barriers, hysteresis and type-II vortices are not solved.

The Gibbs-energy comparison uses Δg = (μ₀Ha² − μ₀Hc²)/2, equivalently [(μ₀Ha)²−(μ₀Hc)²]/(2μ₀), below Tc. Negative favors the superconducting branch. The approximation μ₀ ≈ 4π × 10⁻⁷ H/m is used. There is no superconducting-branch energy supplied above Tc.

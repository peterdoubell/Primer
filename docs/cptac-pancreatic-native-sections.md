# Separate native pancreatic CT review sections

Two unmarked source figures now provide inspectable acquired CT evidence for case C3L-02112. Each contains its own axial section and native coronal/sagittal array sections in soft-tissue (−160 to 240 HU) and wide (−600 to 1000 HU) display windows. These are separate acquisitions, not registered or matched anatomical planes. Source-label names are retained without declaring adequate pancreatic or portal contrast phases.

- [Arterial-labelled original CT](cptac-pancreatic-native-sections/C3L-02112-arterial-labelled-native-ct.png): 365 source planes; selected Z/Y/X indices 154/245/201.
- [Venous-labelled original CT](cptac-pancreatic-native-sections/C3L-02112-venous-labelled-native-ct.png): 713 source planes; selected Z/Y/X indices 511/243/199.
- [Source and display provenance](cptac-pancreatic-native-sections/C3L-02112-native-sections.provenance.json) records both archive hashes, selection/geometry hashes, axial source SOP identifiers, selected array hashes, physical display extents, windows and native crop indices.

The renderer re-hashes each original CT and annotation archive through the same open file used for decoding. Those hashes must match the prior original-geometry audit. It checks each CT object's source identity, axial orientation, matrix, pixel spacing and HU rescale declaration, and checks every native image position against the audited affine. All contour references must resolve to this acquisition's own source SOP and exact physical plane. There is no resampling, interpolation of source arrays, fitting, smoothing, shared crop centre or cross-acquisition contour transfer. Display uses nearest pixels at physical aspect ratio; HU window clipping changes display intensity, not the source values. Per-object rescale slope/intercept are applied before display.

Each original annotation's bounding-box midpoint selects its own nearest native indices. A 25 mm physical review margin is clipped to acquired extent. This is a location aid, not a measured anatomical centre, tumour extent validation, whole-organ crop or proof that every reporting structure is visible. The arrays have 0.703125 × 0.703125 × 0.625 mm source sampling. Native coronal and sagittal sections select existing voxel centres and do not add acquired spatial detail.

Both 1800 × 1200 figures were directly inspected for legibility, separate source-role labels, native index/physical axes and uncropped panel headings on 4 October 2026. That inspection is a figure presentation check, not independent clinical interpretation or an anatomical boundary review. Twenty focused source-selection, time-field, native crop and archive-binding tests passed in the scientific Python environment. Regression tests verify actual figure hashes and retain distinct source acquisitions and all held status fields.

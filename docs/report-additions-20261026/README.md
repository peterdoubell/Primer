# Reporting additions — 26 October 2026

The active catalogue contains 225 selectable templates across 98 source guides: 69 new dedicated examinations, including 29 new radiograph templates. Existing hip arthroplasty radiography remains available. All 156 shipped investigations preserve their original structure and observation vocabulary; their previous guide schemas are archived.

Each examination has named structures and finite descriptors or exact numeric selectors. No clinical observation is preselected. The new classifications are deterministic combinations of reviewed inputs, not image interpretation. Lung-RADS, C-RADS and NI-RADS remain clinician-reviewed category choices.

O-RADS US v2022 and CT/MRI LI-RADS v2018 operate per lesion and require explicit applicability and technically adequate imaging. O-RADS classic-lesion eligibility and LI-RADS ancillary changes require explicit review. They do not generate management recommendations. RECIST 1.1 uses reviewed case-level baseline/current/nadir sums plus non-target and new-lesion status; it reports time-point response, not best overall response. Lesion growth uses actual comparable measurements; volumetric doubling time requires measured comparable volumes and an interval. No spherical volume is inferred.

Frozen native anatomy/source receipts remain unchanged. The bounded runtime inverse covers only the reporting calculator allowlist, exposed calculator IDs and empty-widget availability. The new scope reconciliation explicitly records that these report rows do not establish clinical anatomy/source-renderer completion.

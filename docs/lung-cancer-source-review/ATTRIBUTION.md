# NSCLC-Radiogenomics R01-001 source review

Original dataset: Bakr, S., Gevaert, O., Echegaray, S., Ayers, K., Zhou, M., Shafiq, M., Zheng, H., Zhang, W., Leung, A., Kadoch, M., Shrager, J., Quon, A., Rubin, D., Plevritis, S., & Napel, S. (2017). Data for NSCLC Radiogenomics (Version 4) [Data set]. The Cancer Imaging Archive. https://doi.org/10.7937/K9/TCIA.2017.7hs46erv

Source CT, segmentation, clinical table and AIM annotations: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), as recorded on the [TCIA collection page](https://www.cancerimagingarchive.net/collection/nsclc-radiogenomics/) and series API metadata. See [TCIA usage policy](https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/).

Changes in these review figures: native orthogonal section selection, display windows, nearest-pixel rendering and crops. The marked figure adds original SEG contours. DICOM rescale values are applied for display; source stored pixels, segmentation values and metadata are unchanged. No fitted alignment, source resampling, smoothing, segmentation repair, target relabelling or clinical approval. The source SEG explicitly labels/codes Heart; its identity remains held despite the collection's tumour description and separate case annotations.

Original source archives and DICOM files remain in ignored offline research storage. These review figures are not patient-specific diagnostic outputs and are not deployed reader assets. Source citations and limitations must travel with any later permitted derivative.

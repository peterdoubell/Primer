# Peroneus quartus MRI source candidate

Reviewed 2026-09-30. This is a source acquisition and narrow proposal for the MRI-ankle module. It does not change the runtime, structure requirements or asset ledger, and it does not grant anatomical approval.

The original retrospective MRI study by Yavuz Yuksel, Tarkan Ergun and Ozkan Kose is [Diagnostics 15(18):2329 (2025)](https://doi.org/10.3390/diagnostics15182329). The [licensed article in PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12468075/) and its original Europe PMC XML both explicitly state **CC BY 4.0**. Figure 2 has no separate excluded credit in its XML, caption or image. Its source anatomy is a variant example, not a normality claim for the entire ankle.

The [documented Europe PMC API](https://europepmc.org/RestfulWebService) supplied the exact `diagnostics-15-02329-g002.jpg` file from its Open Access image ZIP. The original repository JPEG is **760 × 331**, **74,814 bytes**, SHA-256 `904a92bbb213421878213f1207ea799e1c1ec8d6d4458175b295febe44df20b0`. It was copied byte-for-byte without resizing, re-encoding, cropping, or changing the original arrows and a/b/c labels. A higher-resolution publisher master has not been verified. The original pixels are retained in [the review file](msk-accessory-ankle-source-review/yuksel2025-peroneus-quartus-mri-fig2.jpg).

The source caption identifies axial fat-suppressed PD FSE MRI in a, coronal T1 FSE in b, and sagittal T1 FSE in c. Panel a labels the accessory PQ belly alongside PB and PL; b/c show a limited visible descending course toward the calcaneus. The study used two 1.5 T scanners with supine, neutral ankle positioning, but the published composite has no DICOM data or exact individual acquisition metadata. Side, age, sex, pain and associated pathology are unreported for this particular figure. The study's aggregate clinical context cannot fill those unknowns.

The proposal suggests only **partial, unapproved image review targets** for the observed PQ belly and the visible musculotendinous course. The original requirements snapshot contained no named PQ requirement; the root agent's scope correction now adds `ankle.peroneus_quartus_muscle.muscle_belly` and `ankle.peroneus_quartus_muscle.visible_musculotendinous_course`, guarded by `anatomical_variant = peroneus_quartus`. The proposal now names those existing targets as partial. It does not apply any ledger/core binding or grant approval. The figure does not prove the full muscle/tendon course, proximal attachment, distal attachment footprint, physical dimensions, dynamic crowding, or symptom causation. Source caption language about the distal direction is not a validated footprint. Accessory soleus and FDAL are not shown, and no 3D anatomy is inferred or constructed.

The caption describes this case's PQ as lateral to the other peroneal tendons, while the study's general definition describes a typical posterior or medial course. These statements remain source-specific; neither creates a universal location or attachment rule.

Access was ordinary and bounded: the publisher page returned 429 and the separate PMC figure page displayed reCAPTCHA, so neither was retried or bypassed. The independently documented public Europe PMC Open Access API returned licensed source XML and the image package. The first package transfer ended with a real socket timeout; one bounded retry completed HTTP 200 with a 384,102-byte ZIP. Only Figure 2 was extracted into this review.

The ZIP inventory contains exactly four JPEGs and four preview GIFs, with no PDF and no second Figure 2 JPEG. Europe PMC's public core metadata supplies an Open Access full-text PDF URL, `https://europepmc.org/articles/PMC12468075?pdf=render`, but the ordinary request returned HTTP 403. That route was stopped without retrying an alternate backend URL. No higher-resolution original stream was acquired; the small repository JPEG remains explicitly limited, and no claim is made that a higher-resolution publisher master does not exist.

The [source context and acquisition record](msk-accessory-ankle-source-review/yuksel2025-source-context.json) retains the source XML hash, complete rights statement, ZIP hash/member, clinical unknowns, and visual observations. All clinical and anatomical approvals remain pending.

The [proposal checks](msk-accessory-ankle-source-review/proposal-checks.json) confirm the JPEG hash and the two current target/context matches. Both coverage guards correctly report `requirement_coverage_partial`. These checks do not establish anatomical fidelity or satisfy the entire requirements.

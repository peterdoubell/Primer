# LNQ case_0571 source review

Idris, T., Somarouthu, S., Jacene, H., LaCasce, A., Ziegler, E., Pieper, S., Khajavi, R., Dorent, R., Pujol, S., Kikinis, R., & Harris, G. (2024). Mediastinal Lymph Node Quantification (LNQ): Segmentation of Heterogeneous CT Data (Version 1) [Data set]. The Cancer Imaging Archive. https://doi.org/10.7937/QVAZ-JA09

Original CT, DICOM SEG and clinical data: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as recorded on the [collection page](https://www.cancerimagingarchive.net/collection/mediastinal-lymph-node-seg/) and per-series metadata. Follow the [TCIA usage policy](https://www.cancerimagingarchive.net/data-usage-policies-and-restrictions/).

Review derivatives: native orthogonal section selection, DICOM rescale application for display, display windows, nearest-pixel rendering, and direct original-annotation contour overlays. The offline surface uses the source binary selection at isovalue 0.5. All source components and supplied coordinate differences are preserved. No source resampling, component removal, smoothing, decimation, fitted registration, invented station identity or clinical approval. Native 2.5 mm slice sampling is retained.

The original CT/SEG archives, reconstructed annotation array and mesh stay in ignored research storage. No runtime media or clinical fidelity binding has been added. These are review artefacts, not diagnostic outputs. Attribution and scope limits must accompany later permitted derivatives.

# Original pancreatic contour coordinates and volume semantics

The original C3L-02112 annotations now have an inspectable 3D line representation and an exact source-coordinate export. [Separate 3D source outlines](cptac-pancreatic-contour-geometry/original-contour-polylines-3d.png) show all 43 arterial-labelled and 49 venous-labelled original CLOSED_PLANAR contours in native LPS millimetres. The export retains all **8,249 source vertices**, encoded as **24,747 original DICOM decimal strings**, without float reformatting, quantization, registration or repaired geometry. Only each original planar closing edge is displayed. No between-plane faces, caps, interpolation, fitted surface or volumetric lesion model is supplied.

[Coordinate and metadata export](cptac-pancreatic-contour-geometry/original-contour-geometry.json) binds each contour to its source ROI number, original contour number, native acquired CT plane/SOP, annotation archive hash and prior selection/geometry audit. An [independent original-archive readback](cptac-pancreatic-contour-geometry/original-coordinate-readback.json) compared every exported decimal component with a fresh reading of the corresponding audited RTSTRUCT: all 11,406 arterial and 13,341 venous components matched as original strings. This verifies export fidelity, not source anatomical correctness.

The ROI-volume field (3006,002C) is defined in cubic centimetres by [DICOM PS3.3 2026d C.8.8.5](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.8.5.html). For both acquisitions, current selected CSV rows and original RTSTRUCT fields agree exactly: 12.411718 cm³ arterial-labelled and 12.117638 cm³ venous-labelled. The difference from our annotated-centre slab arithmetic therefore cannot be dismissed as CSV-versus-DICOM unit disagreement. It also does not identify the original integration algorithm.

Both original RTSTRUCTs name `OHIF-XNAT Viewer 3.2.0` and MANUAL ROI generation. Neither contains ROI Generation Description or ROI Derivation Algorithm Identification. No original contour contains Contour Slab Thickness (3006,0044) or Contour Offset Vector (3006,0045). The source model name alone cannot establish the precise exporter build, volume algorithm, missing-plane interpretation or end-cap conventions used for these specific objects.

Neither ROI Contour item declares **Source Pixel Planes Characteristics Sequence (3006,004A)**. This matters: [DICOM C.8.8.6.4](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.8.8.6.4.html) gives absent-ROI semantics for a source pixel plane lacking contours when that sequence is present. Its grid-specific condition is not met here. Consequently the two acquired venous planes 534/535 remain unannotated with unresolved ROI presence; they are neither automatically filled nor declared empty. The source itself, not a general assumption about contour stacks, must determine any future interpretation.

The retained [TCIA annotation protocol](https://www.cancerimagingarchive.net/analysis-result/cptac-pda-tumor-annotations/) describes selected lesion segmentations, separate targets, radiologist annotation/review, and volume reporting in metadata. It does not give a reproducible volume integration or endpoint formula in the protocol text. The page copy used here was acquired on 3 October 2026 and is fingerprinted in the [source rights/metadata receipt](cptac-pancreatic-source-review/source-metadata-and-rights-review.json); browser retrieval on 4 October returned HTTP 500, so no newly retrieved page text is claimed. A general publisher protocol or viewer interpolation option cannot be substituted for case-specific source construction evidence.

The 3D figure was directly inspected on 4 October for separate acquisitions, physical axes, readable source-count labels and preservation of the visible gap near the venous stack's superior end. This is presentation inspection, not independent clinical assessment of the ROI or alignment between phases. Twenty-four scientific source/export/contour checks passed. Tests bind every source reference/count, retained decimal coordinate, absent metadata declaration, figure hash and held surface status. Original image and annotation grants remain separately documented in the [source attribution](cptac-pancreatic-source-review/ATTRIBUTION.md).

The original CSV/RT tracking discrepancy, injection-relative phase adequacy, source pathology, positive end contours and volume construction remain unresolved. Complete pancreas, ducts, arterial/venous structures, neural pathways and all other reporting targets still require additional source anatomy and independent review. No new clinical fidelity credit, runtime promotion or 3D lesion-surface approval is claimed. The full all-radiology goal remains active.

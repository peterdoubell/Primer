# Runtime MSK reference-image rights reconciliation — 26 September 2026

The completeness audit now inventories the actual reference figures supplied by
current reporting and tracked supplementary lesson routes, independently of
which assets have been assigned anatomical requirements. An unused complete
set of reviewed examples cannot hide additional unreviewed figures still shown
in the product.

The inventory includes `key_images`, `structure_atlas` and
`anatomical_illustrations` from all 22 core MSK references, the eight additional
named cross-specialty investigations, and 20 backing/supplementary lesson
references. Repeated images are one resource with every usage retained.
This is the static clinical/anatomical gallery inventory. Project-authored
lesson plates, generated context photos, model sources and linked reading
retain their separate provenance and review workflows.

The starting inventory contains **172 distinct reference images**: 30 locally
preserved open figures, 141 Radiology Assistant URLs and one Wikimedia image.
The earlier 90-publisher-image count described only the 22 core reporting
references, so it did not capture the full supplementary scope.

## What the new check establishes

`tools/msk_runtime_rights.py` builds the inventory from effective current data.
It does not trust a manually maintained list to represent what is displayed.
A local resource needs a byte-matching evidence record, a reviewed commercial
reuse/redistribution basis, attribution, and its rights evidence file. Unknown
resources, missing files, changed bytes or absent grant evidence remain
unverified. A future timestamp does not repair missing proof. If a recorded
rights-document hash is supplied, the document must still match it.

Remote reference images currently have no byte verification in the delivery
path. They remain unresolved until appropriate permission is documented and
reviewed source bytes are preserved for reliable delivery. This is a product
readiness rule, not a claim that all remote linking is legally prohibited.
The check does not download or republish the unverified publisher catalogue.

The main fidelity command includes this independent rights result and cannot
return clinical/commercial ready without it. Calling the lower-level audit
without a runtime inventory leaves readiness unproven. Rights clearance never
grants anatomical approval, changes a clinical modality, or satisfies missing
structure requirements.

## Reconciled public-domain teaching composite

The existing `nuclear-general-image-3` is Kieran Maher's **SPECT/CT teaching
composite**, listed on the [Commons source page](https://commons.wikimedia.org/w/index.php?title=File:SPECT_CT_fusion.jpg&oldid=723009457).
The page identifies the author's worldwide public-domain dedication and a
fallback unrestricted-use grant. This is that file's permission record, not a
blanket license on Wikimedia-hosted media.

The original JPEG was preserved unchanged at
`web/reference-media/source-figures/spect-ct-fusion.jpg`:

- 17,246 bytes; native 487 × 544 pixels.
- SHA-256 `6f13b7c97b2d46eda574e5d5a75e7fd3bf3da7c57506a6f440b8ba961e561a7e`.
- Original file: <https://upload.wikimedia.org/wikipedia/commons/b/bd/SPECT_CT_fusion.jpg>.
- Credit: Kieran Maher, public-domain author dedication, unmodified via Commons.

The raster was inspected: it is a small SPECT/CT composite with separate
functional and anatomical panels and a fusion panel. Its visible caption now
states that it is a teaching composite at its original pixel resolution,
without a high-resolution anatomy or diagnostic-validation claim. It retains
its source credit and source link. No normality, tracer, diagnosis or MSK
structure binding was inferred.

The new local-source registry pins this file's reviewed bytes. The image loader
accepts registered existing source files only and rejects unknown files,
traversal, unsupported types and checksum changes. This creates a reusable
path for future properly licensed replacements without broadening arbitrary
image access. The corresponding evidence record clears only source rights;
clinical and anatomical fidelity remain pending.

## Publisher sources still unresolved

The [Radiology Assistant information page](https://radiologyassistant.nl/more/radiology-assistant/information)
does not provide an open commercial image license. Its linked app's
[legal agreement](https://doradiology.com/RA2Legal.pdf) addresses app content reuse;
it does not prove identical terms govern every website visitor. The
[author guidelines](https://radiologyassistant.nl/guidelines-for-authors)
also do not grant downstream commercial redistribution. Some article figures
have separate third-party credits, so a blanket inference is especially weak.

The [website disclaimer](https://radiologyassistant.nl/disclaimer), found during
the broader permissions investigation, expressly permits educational reproduction
with credit to the original author and Radiology Assistant. This is relevant
existing permission; the word educational does not itself imply a noncommercial
restriction. Earlier audit statements must be read with this clarification.

The 141 current URLs remain **unresolved for this commercial release**, because
the proposed commercial hosting/adaptations, item-specific third-party credits,
full-resolution files and byte-bound delivery still need reconciliation. They
are not classified as wholly unlicensed or unlawful. The prepared inquiry asks
for confirmation of how the existing permission applies and for any additional
terms, rather than assuming a new paid license is always necessary. No source
image was removed just to improve counts; anatomical requirements are unchanged.

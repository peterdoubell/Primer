# Electricity and electromagnetism workbench

The two existing lesson bindings now mount a scoped workbench covering DC networks and signed cells, charge transfer and wall polarization, material conduction, discharge onset, finite moving magnets, rotating coils, conducting-pipe braking, parallel-wire forces and loaded coupled windings. Original assessments and illustrations remain intact; authored teaching explains the activities and their physical domains.

Current evidence is indexed in `review.json`. The independent numerical tools are ordinary repository tools and run in the regression suite. The authenticated reader proof covers station mounting, complete dynamic narration, invalid-input recovery, reset behavior and plotted coordinates across presets and numeric-control boundaries at 390px and 1440px. Source provenance and derivation limits are in `teaching-scope.md`.

`runtime-inverse.json` strictly restores the four changed shared runtime/data files to PR170 for historical comparisons. It does not grant prior evidence to the new models. `prototype/` contains frozen earlier prototype evidence, not current integration approval. Production verification is recorded separately during release. The broader fidelity goal remains incomplete.

# Illinois teaching meshes for Müllerian variants

The University of Illinois and Knox College open textbook supplies named unicornuate, didelphys and bicornuate uterus teaching meshes. The source chapter lists all three STL attachments under CC BY 4.0. Its preface identifies the 3D models as teaching material developed for the textbook, and its contributors identify Janet Sinn-Hanlon as lead modeler. [Source models](https://med.libretexts.org/Courses/University_of_Illinois/The_Female_Reproductive_System_and_Women%27s_Health_through_a_Multidisciplinary_Lens/10%3A_Models_for_3D_Printing/10.03%3A_Pathological_Models_for_3D_Printing) · [Contributors](https://med.libretexts.org/Courses/University_of_Illinois/The_Female_Reproductive_System_and_Women%27s_Health_through_a_Multidisciplinary_Lens/00%3A_Front_Matter/02%3A_Authors_and_Contributors)

The original files are binary STL. The audit records each revision, SHA-256 digest and complete face count. It constructs an indexed Float32 and Uint32 representation that reproduces every original triangle coordinate word in order. Coordinate edge incidence is two for every edge. Each model has one connected coordinate component. The audit found zero zero-area triangles.

The browser review verified the compressed and decoded checksums, submitted every source triangle to WebGL and confirmed that rotating each model changes its rendered pixels. These authored meshes show gross form for teaching. They supply one unlabelled print surface each in independent model coordinates. Patient-specific cavities, cervical or vaginal duplication, physical calibration and clinical classification require source imaging and specialist review.

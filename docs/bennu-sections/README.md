# Measuring Bennu from the OSIRIS-REx shape archive

The lesson uses the complete 3.25 m, 6.37 m and 12.6 m v21a global altimetry shape models. The PDS XML records, kernel identifiers, checksums, model credits and photograph URL are recorded in the activity’s source.json. The original photograph is the 12-image PolyCam mosaic from 2 December 2018. It is displayed beside the reconstructed shape in its own camera view. [Archive](https://naif.jpl.nasa.gov/pub/naif/pds/pds4/orex/orex_spice/spice_kernels/dsk/) · [NASA photograph](https://science.nasa.gov/resource/bennu-mosaic/)

The archive’s Cartesian vertex coordinates are converted from kilometres to metres. The binary transport stores every source coordinate as float64, followed by every original triangle index as uint32 (converted from one-based indexing). A separate float32 display copy feeds WebGL. Coincident seam vertices are merged only for the topology check. Every undirected edge has two oppositely wound incident faces; all three closed models have Euler characteristic two.

For each model the surface area is the sum of the individual triangle areas, and the enclosed volume is the sum of the oriented origin-to-face tetrahedral volumes. The finest model encloses 61,310,801.661 m³. For a selected cutting plane the browser intersects each triangle with that plane and integrates the resulting oriented boundary to find area. The learning controls use left endpoints, midpoints or trapezoids to estimate the volume from equal slabs. Reference profiles contain 129 positions along each axis.

For an independent numerical comparison, the verifier reads each original DSK with CSPICE through SpiceyPy, compares every displayed vertex and triangle, recomputes volume about a different origin, and sums the areas of cuts through the individual origin-to-face tetrahedra. Across 81 checks the largest difference from the stored section areas was less than 0.000001 m². These are checks against the particular archive models; their nominal resolution limits the surface relief represented.

To reproduce, place the six files listed in the source index and NASA’s original image in `.research/bennu-v21a/`, using `bennu_dec10.png` for the image. Run `tools/geometry_sources/package_bennu.py` and `tools/geometry_sources/verify_bennu.py` with NumPy and SpiceyPy 7 (authoring dependencies). The generated large files are served statically under `/source-media/reference-media/lesson-sources/`.

# Upstream pancreatic ducts and vessels: source acquisition

Acquired a separate original upstream BodyParts3D/Anatomography packet containing **25 version-manifest-selected elements and 26,488 source face records**. Targets include pancreatic duct tree, pancreatic parenchyma, common hepatic duct, splenic and superior mesenteric veins, coeliac trunk, hepatic/gastroduodenal arterial trunks and source-defined portal/SMA compound groups. Original ZIP and extracted OBJ arrays remain in ignored research storage. No anatomy is generated, fitted to HRA or registered to the C3L-02112 CT case.

The [archived BodyParts3D download page](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html) explicitly labels its v4.0 bulk meshes as 99% polygon-reduced. The current reader already uses selected meshes from that archive; their availability cannot establish fine duct or vessel fidelity. A secondary downloader suggested an upstream route, but its full-resolution claim is not accepted as source-quality evidence. We inspected its request format without executing its code, then obtained the manifest, lookup tables and OBJ packet directly from the original upstream server.

The original manifest returned by `get-info.cgi` declares Data Version 4.3, Objects set 4.3 and FMA 3.0 tree version. Both IS-A and PART-OF lookup tables were acquired from the same original endpoint. Selection uses the actual manifest component IDs, retaining every constituent of the requested source groups. Each requested FJ element must have a valid representation mapping, and the returned ZIP must contain each element exactly once. CRC checks cover the complete original ZIP, and every selected original OBJ is fingerprinted and its original header retained. Local SHA-256/ZIP CRC are integrity evidence, not publisher cryptographic checksums or anatomical validation.

Ten returned representation IDs differ from the IS-A lookup. They match the original PART-OF lookup rather than being replaced with the requested identity. For example, pancreatic duct tree FJ1896/FMA63103 was requested through IS-A representation BP20579 but returned as BP23800, with a PART-OF header and matching source concept. All source identities are retained separately. Empty/unavailable PART-OF rows do not authorize arbitrary aliases: every returned BP/concept pair must match an actual original row in at least one source table, and every OBJ must declare the selected compatibility version, file ID, representation ID and concept ID.

The original packet includes two separate parenchymal elements FJ1895 and FJ2629. They are not silently merged, treated as separate organs or deduplicated. The portal compound comprises source left/right portal trunk constituents; it is not asserted to provide a standalone extrahepatic main portal trunk. The source SMA compound includes distal branch components; its parent label cannot grant a complete independently delineated local SMA lumen/wall. A pancreatic duct **tree** label cannot by itself establish separate main/accessory ducts, exact duct endpoints, lumen versus wall or every reporting requirement.

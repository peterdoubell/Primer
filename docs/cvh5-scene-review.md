# Source scene placements and authored appearance controls

The CVH5 U3D now has a complete source hierarchy and appearance inventory: one group, 47 model occurrences and 41 shader/material pairs. All group/parent references, original matrix bytes, shader-list bindings, raw material floats and source block hashes are retained. Cyclic or unresolved parents and ambiguous multi-shader appearance bindings are rejected. Candidate geometry and normal arrays remain linked by their exact hashes.

The [ECMA-363 parent transform](https://www.ecma-international.org/wp-content/uploads/ECMA-363_3rd_edition_june_2006.pdf) uses column-major storage. The source group `CVH5_116` applies a translation of approximately (-186.517, -112.737, -93.012) native units. All 47 model-parent matrices are identity, and every resulting linear determinant is one. No extra unit multiplier, coordinate fitting or topology repair is introduced. The declared scale remains 0.001 metres per native unit. Placed candidate positions/normals, bounds and matrix hashes are explicit; this is a source scene frame, not an acquired clinical orientation or source-section registration.

Raw material opacity is 1.0 for every material. The original PDF carries separate view controls: one named view sets `Skin` visible with opacity 0.5; the other hides it. Both include an unnamed identity-node override and reset states before applying overrides. Source camera matrices, projection, CAD lighting and solid render mode are retained without script execution. PDF view/node opacity controls are distinct from U3D materials, as described in the [PDF reference](https://opensource.adobe.com/dc-acrobat-sdk-docs/pdfstandards/pdfreference1.7old.pdf).

The assembly sheet uses source group placements, authored diffuse colours, candidate encoded normals and explicit named visibility/opacity controls. It shows both authored skin states from two review cameras, retaining every visible candidate triangle. Lighting, camera selection and transparency compositing are approximations; original renderer pixel equivalence is not claimed. Unnamed override scope and PDF view-transform application remain unverified, and the review does not silently apply them as proven. Authored atlas colours are not biological tissue, enhancement or perfusion signals.

These relationships make whole-pelvis interface review possible while preserving the original data. They do not clear the experimental RH/UIC1 decoder, quantized normals, arbitrary anatomical partitions, missing structures/courses, clinical axes or registration. All records retain no clinical approval or runtime/model coverage promotion. Original U3D/PDF and earlier candidate artifacts remain unchanged. Full radiology counts and image-rights counts are unchanged.

Reproduce the scene inventory with `python -m tools.anatomy_sources.review_cvh5_scene --source docs/cvh5-pelvic-source-review --candidates docs/cvh5-candidate-geometry-review --normals docs/cvh5-normal-interpretation-review --output docs/cvh5-scene-review`; read the original views with `python -m tools.anatomy_sources.review_cvh5_pdf_views --pdf .research/anal-source-review/pone.0132226.s003.pdf --source docs/cvh5-pelvic-source-review --output docs/cvh5-scene-review`; render with `python -m tools.anatomy_sources.render_cvh5_scene --scene docs/cvh5-scene-review --candidates docs/cvh5-candidate-geometry-review --normals docs/cvh5-normal-interpretation-review`. Tests cover known transform/normal cases, invalid hierarchy, complete source bindings, authored skin controls and explicit display limits.

The PDF parser explicitly unwraps boolean values. A truthiness error that treated a false visibility object as true was caught by the source-view tests and corrected before retaining the final assembly sheet. The inspected final panels contain 47/47 occurrences with skin visible and 46/46 with skin hidden.

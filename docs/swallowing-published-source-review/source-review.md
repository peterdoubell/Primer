# Swallowing reporting scope and original field-of-view reference

The fluoroscopic swallowing investigation is `ra.swallowing`, in the shared esophagus/swallowing curriculum lesson. The full effective reporting scope now lists 81 groups, 486 source-instantiated parts and 1,458 image/schematic/model obligations. Every actual side, tissue, bolus, variant, lesion, trial and frame/interface must be instantiated separately; this list is a known floor, not complete verified anatomy.

Oral and pharyngeal tissues, velopharyngeal/vallecular/pyriform relationships, laryngeal inlet/fold/subglottic interfaces, pharyngoesophageal and acquired downstream passage, muscles/neural connections, devices and treated tissues remain required. Twenty-two event groups require actual temporal source evidence. The report now records acquired pulse/recorded frame rates, trial/bolus context, timing/order/gaps, coverage and limitations. Static CT, still figures and the orientation model cannot supply these functional findings.

Five unsupported normal presets were removed. Asymmetry no longer uniquely labels unilateral paresis, observed cough absence is not assigned a universal risk ranking, and a tested trial/manoeuvre is not a general diet-safety guarantee. Physiological pressure, neurological mechanism, tissue identity and clinical management remain separately supplied evidence. The adult ESSD–ESGAR technical consensus is not automatically a pediatric protocol or evidence of a depicted patient's age. These reporting changes require independent radiologist/swallowing-team review.

Primary references: [ESSD–ESGAR technical consensus](https://pmc.ncbi.nlm.nih.gov/articles/PMC12081525/), [ASHA VFSS resource](https://www.asha.org/practice-portal/resources/videofluoroscopic-swallow-study/), and [RA source approach](https://radiologyassistant.nl/head-neck/swallowing/swallowing-disorders-update).

# Radiology illustration sources

These plates are deterministic reasoning diagrams, not synthetic diagnostic
images.  Each one makes the lesson's acquisition, visible sign, discriminating
relationship, or management consequence inspectable in source.  Every one of
the 95 generator-owned lessons has its own bespoke composition; the generic
drawing grammar remains only as an explicit fail-safe and is regression-tested
out of the shipped curriculum.

The drawing grammar uses semantic marks for clinically honest schematics (for
example, aortic wall syndromes, haemorrhage compartments, organ anatomy,
modality physics, and tracer-target relationships).  It deliberately falls
back to neutral evidence or decision glyphs when a diagnostic appearance
cannot be represented faithfully.  Flow specs author their own role headings,
and every curriculum entry includes a structured long description containing
all headings, labels, details, and the takeaway.

Regenerate, bind, and audit them from the repository root:

```sh
.venv/bin/python tools/generate_radiology_illustrations.py \
  --render --overwrite --sync-curriculum --check \
  --contact-sheet /tmp/primer-radiology-contact-sheet.png
```

Use `--check-determinism` after rendering to compare every generated byte with
a fresh isolated render.

The twelve source-coverage additions live in `reference_expansion.py` and use
original geometric anatomy schematics with HTML text equivalents. Clinical
case images remain at the linked source articles. See
`docs/radiology-reference-coverage.md` for the source map and report templates.

Three supplemental comparison plates are defined in `companions.py`. The same
render/sync/check commands include them; overview regeneration preserves the
companions, and the contact sheet includes all 99 clinical illustrations (198 WebPs).

# Bravura engraving font

Unmodified Bravura OpenType font by Steinberg, distributed under the included
SIL Open Font License 1.1. This is a build-time engraving dependency; the website
serves pre-rendered notation plates and does not require a remote font request.

Source: https://github.com/steinbergmedia/bravura

SMuFL uses four staff spaces per em. The engraving helper positions the clef's
reference origin directly on G4, F3, or C4, rather than drawing an approximate
symbol or depending on a platform's Unicode fallback font.
